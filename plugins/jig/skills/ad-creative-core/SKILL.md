# 광고 편집 공통 기반

**이 스킬만으로는 광고를 만들지 않는다.** 여기는 "어떻게 조작하는가"이고,
"무엇을 만드는가"는 목적별 스킬이 정한다.

| 목적 | 스킬 | 판정 기준 |
|---|---|---|
| 클릭·구매 (성과 광고) | **`ad-performance`** | 훅률·CTR |
| 인지·태도 (브랜드 필름) | **`ad-brand`** | 완성도 |

**둘 중 하나를 반드시 고른다.** 섞으면 둘 다 실패한다 — 성과 규율은 "컷당 한 메시지·거친 톤"을
요구하고 브랜드 규율은 "정갈한 위계·정교한 마감"을 요구해서 정면으로 부딪힌다.
모르면 사용자에게 묻는다: **"판매용인가요, 브랜딩용인가요?"**

## 전제 조건

- Jig 플러그인(또는 Jig 커넥터)이 연결돼 있어야 한다. 이 스킬의 도구는 전부 Jig MCP 도구다.

## 절대 규칙 — 목적과 무관하게 어기면 안 되는 것

1. **없는 사실을 만들지 않는다.** 가격·할인율·기간·수량·인증·효능·순위·구성품 개수는
   **사용자가 준 것만** 쓴다. 없으면 비워두거나 묻는다.
   - 프레임을 보고 추측한 수치도 금지다. "40 pieces of wood" 처럼 그럴듯한 숫자를 지어낸
     사례가 실제로 있었다(2026-08-02). 한쪽 규율에 몰입하면 이 규칙을 놓친다.
2. **실영상 프리뷰 없이 완료 선언 금지.** "구조가 렌더됐다" ≠ "광고로 봐줄 만하다".
3. **인물 얼굴·핵심 피사체를 가리지 않는다.** 눈대중 말고 `get_frame_regions` 의 `subject_bbox` 와
   레이어 박스를 좌표로 대조한다.
4. **배치 응답의 `warnings` 를 반드시 읽는다.** 서버가 세 가지 조용한 실패를 잡아준다 —
   텍스트 폭 초과, 도형 위에 텍스트를 따로 얹은 것, 검증 안 된 수치.
   `failed: 0` 이어도 `warnings` 가 있으면 결과물은 망가져 있다. **경고가 뜨면 고치고 다시 확인한다.**
5. **덮어쓰기 전 체크포인트 확인.** 망치면 `restore_edit_checkpoint`.
6. **"이 이미지 참조해서"는 `generate_image(reference_image_urls=[...])` 로 이행한다.**
   프롬프트 묘사로 흉내 ✗ / 생성 후 편집으로 맞추기 ✗ / `add_image_layer` 합성으로 대체 ✗ — 전부 지시 불이행이다.
   검증은 눈이 아니라 데이터로: 생성된 이미지의 `reference_image_urls` 가 실제로 채워졌는지 확인하고, 비어 있으면 그 컷은 폐기 후 재생성.
   지시가 없어도 착수 시 **대화 첨부 이미지**와 **프로젝트 업로드 자산**(`get_reference_images` + `generated_images` 중 "직접 업로드")을 먼저 훑는다 — 찾으면 용도 한 줄 알리고 진행, 없으면 되묻지 말고 평소대로.
7. **렌더는 사용자가 시켰을 때만 돌린다.** 제작 완료 = 프리뷰 QA까지. 완료 보고에서 프리뷰를 보여주고 "렌더 돌릴까요?" 한 줄로 묻는다. "만들고 렌더까지"처럼 미리 위임한 경우만 예외이며 그 위임은 해당 1건에만 유효하다.

## 워크플로 (공통 골격)

0. **목적 선언** → `ad-performance` / `ad-brand` 중 하나 로드
0-b. **"처음부터 만들어줘"(클립이 없는) 요청이면 `references/pipeline.md` 를 먼저 따른다** —
   기획→이미지 레퍼런스 체이닝(라벨 환각 QA)→영상 생성(모션 절제)→draft 조립→
   compact_clip_timeline→나레이션. 그 산출 draft 로 아래 워크플로에 진입한다.
1. **파악**: `get_edit_draft`(summary) → 포맷/클립/기존 레이어/자막존
   - **업로드 영상(우리가 만들지 않은 것)이면 `analyze_video` 먼저.** 컷 경계·컷별 대표 프레임·
     피사체 위치가 나온다. **still_url 을 직접 열어보고** 무엇이 찍혔는지 판단할 것 —
     응답은 측정값만 담고 해석은 하지 않는다.
2. **자리 확정**: `get_frame_regions(video_id=…)` 를 컷마다 부르고 `suggested_text_zone` 을 스펙에 적는다
3. **색 확정**: `get_frame_palette` → 응답의 `scheme` 8토큰만 쓴다
4. **구축**: `apply_edit_batch` 한 방 (delete 잔재 + add_layer 전체)
5. **클립을 손본다**: `set_clip_framing` 으로 컷마다 `grade` 를 다르게, 히어로 컷에 `freeze`+`punch`,
   경계에 `transition`, 장식 레이어에 `drift`. **레이어만 얹고 끝내면 그림판이다.**
   값은 `references/craft.md` §10.
6. **QA**: `preview_edit_frame` 에 `at_ms_list` 로 일괄 → **이미지를 직접 보고** 검사
7. **완성 보고**: 프리뷰 첨부 + "렌더 돌릴까요?" — `render_edit_draft` 는 승인 후에만 (절대 규칙 7)

## 밀도 — 요소는 많이, 읽을 것은 적게

**목표 20~30 레이어** (12~15초 3~4컷 기준, 컷당 7~10). 8~9개는 와이어프레임이다.

밀도를 오해하면 안 된다. 늘리는 건 **요소 수**지 **읽어야 할 문장 수**가 아니다.

| 층 | 개수 | 역할 |
|---|---|---|
| 읽는 텍스트 | 컷당 **1개** | 헤드라인. 이것만 "읽힌다" |
| 보조 텍스트 | 2~4 | 라벨·캡션·각주. 훑고 지나가는 것 |
| 도형·장식 | 6~12 | 룰, 바, 배지, 하이라이트, 코너, 블롭 |
| 컨테이너(프레임) | 2~5 | 칩·카드·CTA 박스 |
| 아이콘·기호 | 2~5 | 화살표, 체크, 이모지 |

**밀도가 산만함이 되는 경계**: 같은 위계의 요소가 **3개 이상 동등하게 경쟁**하면 실패다.
장식은 전부 **시선을 헤드라인으로 몰아주는 방향**이어야 한다 — 그렇지 않은 장식은 빼는 게 낫다.

**예외**: 브랜드 스킬의 「미니멀 럭셔리」 레시피는 요소 2개 이하가 정답이다. 레시피가 밀도를 이긴다.

**밀도·모션은 소재 유형을 먼저 정하고 따라간다 (실표본 교정)** — 한쪽 규칙을 다른 쪽에 적용하는 것 자체가 반려 사유:

| | **브랜드 필름형** (15초 내외, 씬 전환 위주) | **롱폼 고정헤더형** (30~60초, 나레이션 상세형) |
|---|---|---|
| 레이어 수 | 5~9장, 씬마다 교체 | **3~8장, 전 구간 고정** |
| 타이밍 | 씬 단위 start/end | **startMs 0 → 전체 길이** |
| 모션 | **필수** + delayMs 90ms 스태거 | **넣지 않는다** — 상단 고정 문구는 원래 안 움직인다 |
| 내용 운반 | 디자인 레이어가 운반 | **자막이 운반** (큐마다 강조 run) |

판단이 서지 않으면 소재의 기존 레이어 타이밍을 보고 따라간다 — 전 구간 고정이면 고정형이다. 실측: 56초 소재가 디자인 3장으로 그대로 승인됐다. 개수를 채우려고 늘리지 말 것.

## 도구 함정 (실측)

- **⚠️ 텍스트 내용 필드는 `text.text`** (`content` 아님). 틀리면 **에러 없이** 기본값 "텍스트"가 렌더된다. 색은 `fontColor`.
- **⚠️ 모션은 `motion: { enter: { type, durationMs, easing, delayMs } }`.** 평평하게 보내면 `whitelist` 가 통째로 벗겨내 `motion: {}` 이 되고 응답은 `failed: 0` 이다. `type` 에 `fadeIn` 은 없다(`fade`).
- **⚠️ 프레임 자식은 `positionMode:'flow'`** 여야 한다. `absolute` 면 자식이 전부 (0,0) 에 쌓인다.
- **⚠️ `set_clip_framing` 응답은 `scale/offsetX/offsetY` 만 에코한다.** grade/freeze/transition 저장 여부는 `get_edit_draft(summary=false)` 의 `clipTransforms[clipId].videoTransform` 으로 확인.
- **⚠️ mutate 직후 프리뷰는 반영 전 상태가 올 수 있다.** 클립 변경 후 2~3초 두고 찍을 것.
- **⚠️ 프리뷰 캐시** — 같은 `at_ms` 재요청은 갱신 전 이미지가 온다. 수정 후 QA 는 **at_ms 를 바꿔서**.
- **⚠️ 동시편집 클로버** — 사람이 같은 draft 를 에디터로 열어두면 자동저장이 전체 payload 를 덮어쓴다.
- **⚠️ `add_frame_layer`/`add_text_layer` 응답에 layer_id 가 안 실려 올 수 있다** (`{"status":"ok","formats":[]}`). 프레임 id 는 draft 를 다시 조회해 얻어 `parent_id` 로 쓴다.
- 위치·크기·부모·레이아웃은 `update_layer_box` 로. `update_text_layer` 는 스타일만 patch 한다.
- `drift`/`text_fill`/`perspective` 제거는 `update_layer_box` 에 **`null`**. 생략하면 기존 값이 남는다.
- 레이어 좌표는 **박스 좌상단 기준 0~1**. `textAlign:center` 는 그 박스 **안에서** 가운데다.
- 미디어 URL 은 서명 URL(1시간)이다. **받아둔 URL 을 오래 보관해 재사용하면 400** — 필요할 때 다시 조회한다.

## 정적 마감 6게이트 — 원샷이 실제로 틀리는 것 (실표본 역추출)

사람이 원샷 결과를 손본 내역을 전수 대조하면 **고치는 것이 전부 "정지 화면 한 장의 완성도"다.** 모션·타이밍·레이어 개수는 안 건드린다. 전부 눈대중이 아니라 **세는 조건**으로 검사한다:

| # | 게이트 | 실패 실측 | 통과 조건 |
|---|---|---|---|
| 1 | **판 내 정렬** | 밴드 445px 안에서 위 여백 213 / 아래 43 | 프레임 종속으로 만들 것. 절대좌표를 썼다면 **상·하 여백 차 ≤ 판 높이의 20%** |
| 2 | **폰트 크기 하한** | 하단 소카피 19px → 사람이 32px 로 | 아래 하한표 미만이면 배치 금지 |
| 3 | **패널 기본값** | `#000 opacity 1` 하드엣지 검정 막대 | **스크림이 기본, 단색 불투명이 예외.** 영상 위 패널은 `backgroundGradient` 투명→검정(`angleDeg:180`) |
| 4 | **블리드** | 풀블리드 아트를 캔버스에 딱 맞춤 | 풀블리드 이미지·스트립은 **캔버스 대비 +8~12%, x 음수** (실측 최종본: `1286 @ x=-103`) |
| 5 | **아웃라인** | 골드 그라데 위 **흰색** 아웃라인 → 글자가 번짐 | 아웃라인은 **검정**, fontSize 의 4~6%. 흰 아웃라인 금지 |
| 6 | **배경 밝기 대응** | 밝은 배경에 골드 그라데 → 묻힘 | 금속 그라데 레시피 **앞에** `get_frame_palette` 필수. 밝은 배경이면 단색 + `textShadows` 글로우로 교체 |

**폰트 크기 하한 (렌더px, 9:16 H1920 기준)** — 렌더px = `fontSizeRatio × H² / 1080`:

| 역할 | 하한 | 권장 |
|---|---|---|
| 헤드라인 | **44** | 45~60 |
| 서브헤드 | **28** | 30~38 |
| 라벨·pill·스펙 | **24** | 26~32 |
| 브랜드 소카피 | **28** | 30~34 |
| 하단 주석 | **12** | 12~14 |

16:9·1:1(H1080)도 같은 렌더px 를 목표로 하되 ratio 를 `px/1080` 로 환산한다.

**완료 조건 — `apply_edit_batch` 의 `failed=0` 은 완료가 아니다.** 디자인 레이어를 올린 뒤에는 ① `preview_edit_frame` 최소 1장(고정헤더형 대표 1~2시점, 필름형 씬별) ② 이미지를 직접 보고 6게이트+QA 대조 ③ 걸린 항목 수정 → 재프리뷰, 까지 거쳐야 완료다.

## 카피 규칙

내용(문구)은 기획안/기존 자막/사용자 제공분에서 가져온다. **가격·할인율·기간·수량·인증·효능·법적
문구는 절대 만들어내지 않는다** (절대 규칙 1) — 없으면 비워두거나 묻는다.

**한글 줄바꿈** (반려 다발 지점):
- 의미 단위로 끊는다: `복날엔 / 할인해` ○, `복날엔 할 / 인해` ✗. 글자수로 자르지 말 것.
- 조사·어미 한 글자를 줄 끝/줄 머리에 고립시키지 않는다 (`~의` `~을` `~는`).
- **오퍼는 절대 쪼개지 않는다**: `최대 30% 할인`, `1+1`, `선착순 500명`, 날짜는 한 줄에.
  숫자와 단위(`30`+`%`)가 분리되면 반려.
- 표시용 폰트는 헤드라인 1종 + 본문 산세리프 1종, **총 2종까지** (장식 팝 캡션은 예외 1종 허용).

**오퍼 보호 사각형**: 가격·할인·기간·CTA 는 배치 전에 보호 사각형(텍스트 박스 + 폰트 크기의
0.5배 여백, 세이프에어리어 안쪽)을 먼저 잡고, 그 안에 장식·이미지·블롭·글로우를 **절대 들이지
않는다.** 피사체가 침범하면 장식을 옮기는 게 아니라 레이아웃을 다시 잡는다.
25% 축소 썸네일에서도 오퍼 숫자·단위가 전부 읽혀야 통과.

## QA 체크리스트 (공통)

- [ ] 인물/제품 가림 없음 — `subject_bbox` 와 좌표 대조
- [ ] **텍스트가 의도한 내용으로 렌더됐는지** — 필드명 오타는 조용히 기본값이 된다
- [ ] **배치 응답에 `warnings` 가 비어 있는가** (폭 초과·도형위 텍스트·미검증 수치)
- [ ] **모션이 실제로 저장됐는지** — `summary=false` 로 `motion.enter` 확인
- [ ] 모션 검증은 애니메이션 구간을 3등분해서 (delay+80 / +250 / +450)
- [ ] 컷마다 `grade` 가 다른가 — 전 컷 동일 색이면 편집이 안 들어간 것
- [ ] `drift` 를 건 레이어의 최종 위치가 세이프에어리어 안인가
- [ ] 대비 4.5 이상 — 프리뷰 픽셀로 계산. 알파 배경은 합성 후 값으로

## 피드(정지형) 소재 — IG 피드/캐러셀 (2026-08-30 신설)

> **기획·디자인 문법은 `feed-carousel` 스킬이 정본** (캐러셀 구조, "Corporate Ink" 디자인
> 시스템, 크기 스펙, 콘텐츠 방향). 여기는 도구/공식/함정만.

영상이 아니라 **정지 이미지 게시물**을 만들 때. draft 는 `kind:'feed'` 클립리스이고,
**페이지 = 같은 비율의 formats[]** 다. 레이어 도구는 영상 draft 와 완전히 동일하게 쓰되
`format_idx` = 페이지 번호(0-base)로 조준한다.

- 도구: `create_feed_draft`(project_id, ratio 기본 4:5=1080×1350) → `add_feed_page`
  (`copy_from_idx` 로 템플릿 복제 — 캐러셀 페이지 간 통일감의 핵심) → 레이어 작업 →
  `preview_edit_frame`(at_ms **0**, format_idx=페이지) → `export_feed_pages`(풀해상도 PNG).
- **레이어 타이밍은 전부 start 0** — 정지 프레임은 at_ms 0 을 찍는다. 모션·오디오·자막 무의미.
- 배경: 페이지 `backgroundColor`(기본 #FFFFFF)가 대지 색. 사진 배경이면 풀블리드
  image 레이어(블리드 +8~12% 게이트 4 동일).
- **폰트 공식 주의**: 렌더px = ratio × H²/1080. 4:5(H1350)는 **ratio×1687.5** —
  9:16 값(×3413)도 16:9 값(×1080)도 아니다. 헤드라인 하한 44px 등 6게이트 동일 적용.
- 캐러셀 문법: 1페이지 = 훅(스크롤 스토퍼, 텍스트 크게), 2~N = 본문(페이지당 주장 1개),
  마지막 = CTA. 페이지 간 배경·폰트·정렬축 통일(copy_from_idx 복제 후 내용만 교체).
- **그리드 조화**: 사용자는 `/feed` 플래너에서 IG 프로필 3열 그리드로 미리 본다 —
  연속 게시물이 나란히 놓이므로 톤이 튀는 단발 디자인보다 시리즈 일관성이 우선.
- `export_feed_pages` = 피드의 렌더다 — **절대 규칙 7(승인 후 렌더) 동일 적용.**
  프리뷰 QA 까지 하고 "PNG로 내보낼까요?" 로 묻는다. URL 은 서명 1시간짜리.
- 사람 편집 동선: jig.ai.kr 피드 화면 → 편집기(페이지 탭 + PNG 내보내기). 에이전트 작업 중 사람이 같은 draft 를 열어두면 자동저장이 덮어쓴다.
- **실측 케이스 ("If Animals Had LinkedIn" 5p 캐러셀)**: 커버(보드룸
  단체컷+Anton 헤드라인) → 프로필 카드 3장 → 네이비 CTA. 배운 것 ① 인물 일관성은 히어로 1장 뽑고
  reference_image_urls 체이닝 — 배경·조명까지 시리즈로 묶인다 ② 이미지 생성은 4:5 미지원
  → **3:4 로 뽑고 objectFit cover** (레이어 x/y∈[0,1] 제약이라 음수 블리드 불가, cover 로 충분)
  ③ 프리뷰에서 커스텀 폰트가 전부 기본 폰트로 보이면 잠시 뒤 at_ms 를 바꿔 다시 프리뷰하고, 계속되면 문의한다.
- **⚠️ 피드도 영상과 같은 마감 기준이다 — 플랫 단색 텍스트+민무늬 판은 "그림판" 반려 (2026-08-30 실반려)**.
  초판을 solid 텍스트/흰 사각판만으로 냈다가 통째로 반려됐고, 스토리형 스택으로 재작업 후 통과.
  통과본의 문법: 밝은 실사 위 대형 헤드라인 = **textFx 스티커 팝**(메탈 그라데 4-stop 중간 흰 stop
  + 잉크 스트로크 5% + 흰 이중테 + 하드/소프트 섀도 2겹), 사진→판 경계는 **스크림/페이드**(투명→
  대지색 backgroundGradient)로만, 판은 **radius+drop shadow(effects.shadowColor/Blur) 플로팅 카드**,
  pill·칩·버튼은 frame+자식 텍스트(그라데 bg·보더), 아바타는 **circle 도형 링 + 이미지
  mask:{kind:circle}**, 다크 페이지는 라디얼 글로우(backgroundRadialGradient) 한 겹.
  도구 필드 함정 3건: textFx 스펙 필드명은 **`fx`**(딴 이름은 조용히 벗겨져 "Text" 렌더),
  불투명 도형은 **backgroundOpacity:1 명시**(기본값이 1이 아니라 흰 대지와 블렌드됨), mask
  circle 의 **size 는 반지름%라 원형 크롭은 60~70**(99는 노크롭), layer-box 패치는 `patch:{}` 래퍼.
