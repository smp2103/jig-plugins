# 예능형 자막 스타일링

방송 예능 자막의 룩(금속 광택 + 두꺼운 테두리)을 편집 draft의 **텍스트 레이어**로 구현한다.

> **근거 범위**: ①실제 채택된 소재 2건(폰트 시안 보드, 임플란트 광고) ②AE 원본 역추출 2건(치과 광고, 피트니스 광고)에서 뽑았다. 금속 레시피는 ①, 유퀴즈풍·텍스트 인터랙션은 ②가 근거다. 표본이 작으므로 수치는 "검증된 출발점"이지 분포가 아니다 — 새 소재를 만들 때마다 케이스 로그에 추가할 것.

## 이 문서의 레시피는 Jig만으로 완결된다

**여기 적힌 값으로 Jig 도구만 써서 그대로 재현된다. AE는 필요 없다.**

아래 수치들은 AE 원본에서 한 번 표본을 떠 온 것이고, 그 이식은 **이미 끝났다**. `fontFamily` / `fontSizeRatio` / `textShadows` / `outlineWidth` / `motion`은 전부 `apply_edit_batch`·`update_subtitle_entry`·`add_text_layer`로 넣는 Jig 필드다. 실행 환경(로컬 클로드 코드 / 데스크톱 채팅 / 코워크)과 무관하게 동일하게 동작한다.

- **AE를 열 필요가 없다.** "AE 원본:" 으로 시작하는 줄들은 그 값이 어디서 나왔는지 밝히는 **근거 표기**지, 실행 전제가 아니다.
- 유일한 준비물은 **폰트**다. `list_project_fonts`로 확인해 소재에 없으면 전역 카탈로그(99종)에서 같은 결의 폰트로 캐스팅하면 되고, `fontFamily`만 지정하면 자동 등록된다.

## 톤 축 — 같은 레시피를 "차분하게" / "시원하게" (2026-08-21 투윅스 A/B 실측)

**이 문서의 레시피는 전부 강도 조절이 가능하다.** 스토리형/예능형이어도 "좀 차분했으면" 하는 소재가 있고, 그건 다른 레시피를 쓰라는 뜻이 아니라 **같은 레시피를 낮은 강도로 쓰라는 뜻**이다.

### 사용자가 이렇게 말하면 → 차분(Calm)

> "차분하게", "은은하게", "과하지 않게", "고급스럽게", "프리미엄", "미니멀하게", "정돈된", "담백하게", "브랜드 광고 느낌", "자막이 너무 튄다"

### 사용자가 이렇게 말하면 → 시원(Punch)

> "시원하게", "눈에 빡 들어오게", "크게", "임팩트 있게", "퍼포먼스", "잘 보이게", "촌스러워도 되니 잘 읽히게", "심심하다"

### 강도 대조표 (투윅스 마스크 15초, **같은 푸티지로 두 버전 실측**)

| 축 | 차분 | 시원 | 배수 |
|---|---|---|---|
| 자막 크기 `fontSizeRatio` | 0.0152 (52px) | **0.021 (72px)** | ×1.4 |
| 자막 굵기 | Medium | **Bold** | — |
| 가독성 확보 | **다크 반투명 판**(opacity 0.58) + 흰 글씨 | **판 제거 + 흰 헤일로 4겹**(blur 12·12·24·40) + 다크 잉크 | 박스 ↔ 헤일로 |
| 키워드 강조 | 없음(단색) | **브랜드 컬러 run 1개** | — |
| 헤드라인 | 세리프 46/56px | 산세리프 **82px** | ×1.5 |
| 오퍼 배지 | 59px, 화면폭 72% | **89px, 화면폭 88%** | ×1.5 |
| 모션 | `fade` 위주 | `scale`+`spring`, `slideUp` | 스며듦 ↔ 튐 |

**핵심은 크기가 아니라 "가독성을 무엇으로 확보하느냐"다.** 차분은 **판(박스)** 으로, 시원은 **헤일로**로 확보한다. 박스를 유지한 채 글자만 키우면 화면이 무거워지고, 헤일로로 바꾸는 순간 박스가 사라져 배경이 열리면서 "시원하다"는 인상이 생긴다.

### 차분 톤에서의 레시피 선택

- 금속(골드/실버)은 **쓰지 않거나 실버 1개까지**. 골드는 그 자체가 퍼포먼스 신호다.
- 대사 자막은 **모노** 또는 아래 **어두운 잉크 + 흰 글로우**. 유퀴즈풍 컬러 글로우는 채도를 낮추거나(알파 0.5 이하) 무채 그림자로 대체.

**어두운 잉크 + 흰 글로우 (박스 없는 차분 강조)** — 차분 톤의 대사 자막 표준. 가독성을 박스가 아니라 **흰 외부광선**으로 확보한다(AE 원본: glow 크기35 42% + 흰 소프트섀도 크기21 63%). 박스를 깔면 무거워지고, 여기에 두꺼운 테두리까지 얹으면 뭉개진다.

```json
{"fontColor":"#1A1613","backgroundOpacity":0,"outlineWidth":0,"letterSpacing":-0.5,
 "textShadows":[
  {"color":"rgba(255,255,255,0.9)","x":0,"y":0,"blur":4},
  {"color":"rgba(255,255,255,0.75)","x":0,"y":0,"blur":10},
  {"color":"rgba(255,255,255,0.75)","x":0,"y":0,"blur":10},
  {"color":"rgba(255,255,255,0.55)","x":0,"y":2,"blur":18}]}
```
- **팝·카운트업은 뺀다.** 조립형은 남겨도 된다 — 조립은 원래 "스며드는" 계열이라 차분 톤과 충돌하지 않는다(팝은 튀고 조립은 스며든다).
- 대사마다 폰트를 갈아끼우는 문법도 **2종까지**로 줄인다(표시용 1 + 본문 1). 11종은 퍼포먼스 문법이다.

### ⚠️ 밝은 푸티지에서는 톤과 무관하게 다크 잉크

차분/시원 어느 쪽이든 **밝은 실사 위에 밝은 글씨는 워시아웃된다.** 톤은 강도를 정하는 축이고, 명도 반전은 그와 별개의 철칙이다 — 밝은 배경이면 차분은 "다크 잉크 + 판", 시원은 "다크 잉크 + 흰 헤일로"로 간다. 흰 글씨를 쓰려면 다크 판/스크림 위에서만.

## 두 가지 적용 경로 — 고정 디자인 vs 타임라인 포인트

| 상황 | 도구 | 왜 |
|---|---|---|
| **화면에 상시 박힌 카피** (헤드라인·가격·라벨) | `add_text_layer` / `apply_edit_batch` | 위치·크기를 자유롭게 잡아야 하고 자막존과 별개로 살아야 한다. 확인한 두 소재가 이 방식 |
| **말하는 중간의 특정 자막 한 줄** | **`apply_caption_preset`** | 전역 자막 스타일은 그대로 두고 **그 큐만** 승격. 타임라인 중간의 포인트를 때리는 용도 |

`set_subtitle_style`(전역)은 손대지 않는다 — 사람이 검수한 마스터 스타일이다. 큐 하나만 바꾸는 건 `apply_caption_preset`(또는 `update_subtitle_entry`의 `style`)이고, 이건 **원래부터 되는 기능**이다(운영 데이터 2,126큐 중 1,149큐가 이미 큐 단위 override 사용 중).

### `apply_caption_preset` — 한 줄로 예능 자막

```
apply_caption_preset(draft_id, entry_idx, preset: gold|silver|mono|pill, tone?: auto|light|dark)
```

- 4-stop 그라데이션, 아웃라인 폭(**렌더 글자 px의 5%**, 포맷별 자동 환산), 그림자 색을 **도구가 계산한다.** hex를 손으로 쓰지 말 것
- `tone: auto`(기본)면 **그 큐 시각의 프레임을 1장 렌더해 배경 밝기를 판정**하고 그림자 색을 고른다 (밝은 배경에 흰 그림자를 쓰면 사라지는 문제를 도구가 흡수)
- 되돌리기: `update_subtitle_entry(entry_idx, clear_style=true)` → 전역 스타일로 복귀
- 절제: **연속된 큐에 연달아 쓰면 강조가 사라진다.** 4~5줄에 한 번, 진짜 포인트에만

프리셋 기본 크기는 `gold` 0.075 / `mono` 0.07 / `silver` 0.065 / `pill` 0.042 (화면 높이 대비)로 **전역 자막(0.03~0.06)보다 크게** 잡혀 있다 — "여기만 다르다"가 크기로도 읽혀야 하기 때문. 마스터와 붙이고 싶으면 `size_ratio`로 낮춘다.

## 철칙

1. **금속 그라데이션의 핵심은 중간 흰색 stop이다.** 골드는 `골드 → 흰색 → 골드 → 어두운 골드` 4단. 흰색 하이라이트가 없으면 그냥 노란 글씨고, 있어야 금속 반사로 읽힌다.
2. **그라데이션은 세로(`angleDeg: 180`).** 두 소재 모두 세로다. 가로로 주면 글자마다 색이 달라져 산만해진다.
3. **아웃라인은 fontSize의 5%, 색은 검정.** 106.7px → 5.33, 88.9px → 3.56(4%). 아웃라인 없는 금속 텍스트는 배경에 묻힌다.
   **흰색 아웃라인은 쓰지 않는다 (2026-08-27 실표본 반려).** 골드 그라데이션에 흰 아웃라인 5px를 두르면 글자 가장자리가 뿌옇게 번져 금속감이 죽는다(원샷 실측 — 사람이 `outlineWidth: 0`으로 제거). 밝은 테두리가 필요하면 아웃라인이 아니라 `textShadows` 글로우로.
4. **한 화면에 금속은 골드 1 + 실버 1까지.** 금속 3개면 트로피 진열장이 된다. 위계는 골드=강조(가격·혜택), 실버=설명.
5. **문구는 짧게.** 확인된 예: `너무 힘들지...`(8자), `20만원`(4자), `1개든 10개든`(7자).
6. **레시피를 고르기 전에 `get_frame_palette`로 배경 밝기를 먼저 읽는다 (선행 조건, 2026-08-27 실표본 반려).**
   금속 그라데이션은 **어두운 배경 전제**다. 밝은 배경(흰 벽·밝은 텍스처·수묵 아트)에 골드/실버를 얹으면 그냥 묻힌다 — 원샷이 밝은 수묵 브랜드 아트 위에 골드 그라데 run을 얹었고, 사람이 **검정 단색 + 골드 글로우**로 통째 교체했다:
   ```json
   {"fontColor":"rgb(0,0,0)",
    "textShadows":[{"x":0,"y":0,"blur":10,"color":"rgb(255,222,161)"}]}
   ```
   밝은 배경에서 "금속처럼 보이게" 하는 정답은 그라데이션이 아니라 **어두운 잉크 + 금색 헤일로**다.

7. **그림자 색은 배경 밝기를 따라간다.** 아래 레시피의 흰 그림자는 **어두운 배경 전제**다. 밝은 배경(흰 벽·밝은 텍스처)에서는 흰 그림자가 사라지므로 `rgba(0,0,0,0.3~0.35)`로 바꾼다. 그림자 방향(3.56, 3.56)과 blur(7.11)는 그대로.

{"fontGradient":{"angleDeg":180,"stops":[
  {"color":"rgb(244,203,79)","offset":30},
  {"color":"rgb(255,255,255)","offset":47},
  {"color":"rgb(250,214,67)","offset":65},

{"fontGradient":{"angleDeg":180,"stops":[

가장 범용. 어떤 영상 위에도 얹힌다.

### 유퀴즈풍 — 손글씨 + 컬러 글로우 자막 (2026-08-21 AE 원본 실측 이식)

**유퀴즈 온 더 블럭 자막 = 손글씨 펜 서체 + 무테 + 컬러 소프트 글로우 + 숫자만 노랑.** 굵은 테두리 자막이 아니다 (여기서 한 번 헛짚었다 — 상단 헤드라인 스타일과 혼동 금지).

```json
{"fontFamily":"SDEpilogue-aPen","fontColor":"#F8F7F5","fontSizeRatio":0.019,
 "outlineWidth":0,"letterSpacing":-2.5,"lineHeight":1.29,
 "textAlign":"left","marginL":70,"marginV":760,
 "textShadows":[
  {"color":"rgba(5,17,255,0.95)","x":0,"y":0,"blur":18},
  {"color":"rgba(5,17,255,0.75)","x":0,"y":0,"blur":18},
  {"color":"rgba(5,17,255,0.4)","x":0,"y":0,"blur":40}]}
```
숫자·금액만 run 으로 노랑 `#FCFF00` (예: `[{text:"예, 결국 "},{text:"25만 원",fontColor:"#FCFF00"},{text:"에 임플란트"}]`).

- **AE 원본**: `SDEpilogueTTF-aPen` 116px(1920 comp), 채움 `rgb(248,247,245)`, **획 없음**, 트래킹 -25, 행간 129, "그림자 효과" ×2 — 색 **`rgb(5,17,255)` 파랑**, 거리 0, 부드러움 60, 불투명도 255/64. (컬러는 소재마다 갈아끼우는 포인트 — 빨강 `rgb(255,5,5)` 버전도 같은 프로젝트에 있다.)
- **⚠️ AE 부드러움(60)을 blur 에 그대로 넣지 말 것**: Jig 렌더는 blur 에도 `ds` 스케일(9:16이면 ×1.78)이 붙어 **107px로 퍼져 글로우가 사실상 사라진다** (실측 반려). 안쪽 진한 겹(blur 18 ×2) + 바깥 옅은 겹(blur 40)으로 3겹 쌓는 게 AE 룩에 맞는다 — AE 값은 "얼마나 퍼지나"가 아니라 "얼마나 진한가"로 번역할 것.
- 크기: AE 116px@1920 = 1080폭 환산 65px → 9:16 `fontSizeRatio 0.019`. 키우면 손글씨 특유의 가벼움이 사라진다.
- **배치는 좌측 하단, 영상 위에 얹는다** (`textAlign:"left"`, `marginL` 70). 중앙 정렬하면 유퀴즈 느낌이 안 난다.
- 폰트가 카탈로그에 없으면 `list_project_fonts` 에서 같은 결의 손글씨 펜 서체로 대체한다.

**같이 쓰이는 상단 헤드라인** (검정 밴드 위): GmarketSansMedium 흰색 + 키워드 run 라임 `#86FF37` / 금액 run 노랑 `#F6FF00`, 무테, 검정 소프트 그림자 2겹 `blur 24`(AE 부드러움 48). 2줄 고정 문구.

**레이아웃**: 검정 배경 + 상단 헤드라인 + 중앙 16:9 영상 밴드 + 영상 좌측 하단 손글씨 자막. AE 원본 프레임과 나란히 대조해 통과했다.

## 텍스트 인터랙션 — 유퀴즈 문법의 나머지 절반 (2026-08-21 실측 이식)

**자막 스타일만 옮기면 절반만 옮긴 것이다.** 유퀴즈풍 소재는 대사 자막 위에 **말이 끝나는 지점마다 텍스트 레이어가 튀어나오는 리듬**이 얹혀 있고, 그게 없으면 "손글씨 폰트를 쓴 평범한 자막 영상"이 된다. 실측 소재에서 두 계열이 나왔다.

### A. 키워드 팝 — 한 단어를 크게 때린다

숫자·형용사 등 **2~4자 키워드**를, 화자가 그 단어를 말하는 순간 큰 글씨로 띄운다. 실측: `5만건`, `깔 - 끔`, `친 - 절` (음절을 하이픈으로 벌려 쓰는 게 이 계열의 표기 버릇).

```json
{"fontFamily":"Mungyeong-Gamhong-Apple","fontSizeRatio":0.044,
 "outlineColor":"#000000","outlineWidth":5.5,"letterSpacing":-4,
 "fontGradient":{"angleDeg":180,"stops":[
   {"color":"#FFF9E0","offset":0},{"color":"#FFFFFF","offset":40},
   {"color":"#FFE9A8","offset":62},{"color":"#E3B85C","offset":100}]},
 "textShadows":[
   {"color":"#000000","x":2,"y":2,"blur":0},
   {"color":"#000000","x":4,"y":4,"blur":0},
   {"color":"#000000","x":6,"y":6,"blur":0}]}
```
모션은 `{"enter":{"type":"bounce","durationMs":760,"easing":"spring"}}`. AE 실측 스케일 키프레임이 **0 → 105 → 95 → 103 → 98 → 100 (767ms)** 였고 Jig `bounce`가 정확히 이 곡선이다 — 직접 키프레임을 흉내낼 필요 없다.

- AE 원본: 문경감홍사과체 156px@1920, 채움에 그라디언트 오버레이(크림골드), 획 검정 10px(= fontSize의 6.4%), **"그림자 효과" 5겹**(거리 3 · 방향 135 · 부드러움 0) + 레이어스타일 "선" 3px. 하드 섀도를 5겹 쌓는 건 두께를 만들려는 것이므로 Jig에선 오프셋을 2/4/6으로 벌린 3겹이면 같은 두께가 나온다.
- **2개 이상 쌓을 땐 세로 스택 + 스태거**. 실측은 같은 x, y만 216px 차이로 두 장(`깔 - 끔` 11.44s → `친 - 절` 13.68s), 끝은 **동시에** 사라진다.

### B. 조립형 — 혜택을 한 줄씩 쌓아 보여준다

"A + B 를 다 준다"를 문장으로 읽히지 않고 **명세서처럼 쌓아** 보여주는 계열. 실측: `지르코니아 크라운` / `+` / `잇몸 맞춤 지대주` 3단.

```json
{"fontFamily":"SDEpilogue-bPil","fontColor":"#FFFFFF","fontSizeRatio":0.0328,
 "outlineWidth":0,"letterSpacing":-3,
 "textShadows":[{"color":"rgba(0,0,0,0.9)","x":3,"y":3,"blur":4}]}
```
- **`+` 도 독립 레이어이고 본문과 같은 크기다.** 작게 줄이면 수식이 되고, 같은 크기여야 "항목"으로 읽힌다.
- 타이밍이 이 계열의 전부다. 실측: 등장 `20.05 / 20.62 / 21.39`(간격 570·770ms) → **세 줄이 동시에 23.99~24.92s 페이드아웃**. 즉 *들어올 땐 따로, 나갈 땐 같이*. Jig에선 `start_ms`를 각각 다르게, `end_ms`를 같게 주고 `exit:{type:"fade",durationMs:900}`.
- AE는 각 줄에 `AC IN` 가우시안 블러(50→0) 포커스인을 걸었다. Jig엔 블러 인이 없으므로 **`enter:{type:"fade",durationMs:420}`** 으로 번역한다 — 여기서 `scale`/`bounce`를 쓰면 A계열(팝)과 성격이 겹쳐 위계가 무너진다. **팝은 튀고 조립은 스며든다.**

### ⚠️ 조립형이 뜨는 구간의 대사 자막은 지운다

AE 실측에서 조립 3단이 떠 있는 `20.05~24.46s` 구간에는 **대사 자막이 아예 없다** — 조립형이 자막을 대신한다. 자막을 남겨두면 같은 문구("지르코니아 크라운과 잇몸 맞춤 지대주까지")가 화면에 두 번 뜬다(실측으로 걸림). `delete_subtitle_entry`로 그 구간 큐를 비울 것.

### C. 카운트업 — 숫자를 좌→우로 누적해 겹쳐 쌓는다 (2026-08-21 실측)

`50` → `50 60,` → `50 60, 70대는`. **세 개가 각각 독립 레이어이고, 서로 겹치도록 배치한 뒤 0.35~0.47초 간격으로 하나씩 등장해 끝까지 함께 남는다.** 조립형(B)이 세로로 쌓는다면 이건 가로로 쌓는다 — "연령대가 늘어난다"처럼 **범위가 커지는 말**에 쓴다.

- 겹침이 의도다. 실측 좌표는 글자 폭보다 간격이 좁아 숫자끼리 물린다. 대신 **불투명도 0.6**을 줘서 겹친 부분이 비쳐 보이게 한다 — 불투명하게 두면 뒤 숫자가 가려져 그냥 오타처럼 보인다.
- 폰트는 **얇은 대형 산세리프**(AE: THEFACESHOP 267px). 두꺼운 디스플레이 폰트를 쓰면 겹침이 뭉개진다. 대체 후보: `Paperlogy-2ExtraLight`, `Freesentation-1Thin`, `ONE Mobile Light`.
- 모션은 `scale` + `spring` 420ms (A와 같은 팝 계열 — 숫자니까).
- 글로우: 컬러 그림자 1겹 + 넓은 1겹 `[{시안 α0.75, x3 y3, blur15}, {시안 α0.45, x0 y0, blur28}]`.

### 대사마다 폰트를 갈아끼우는 게 이 문법의 뼈대다

피트니스 광고 39초 소재의 자막 11줄에 **폰트 11종이 전부 다르다.** 손글씨↔각진고딕↔명조↔둥근볼드를 대사 성격에 따라 계속 바꾼다. 자막을 한 폰트로 통일하면 아무리 스타일을 얹어도 유퀴즈가 안 된다.

같이 따라오는 규칙이 **컬러 외부광선(AE "외부 광선" 레이어 스타일)** 이다. AE 값 → Jig 매핑:

| AE 외부광선 | 성격 | Jig `textShadows` |
|---|---|---|
| 크기 52, 진한 컬러(파랑/빨강/마젠타) | 손글씨 자막의 시그니처 발광 | 같은 색 3겹 `blur 18 ×2(α.95/.75) + blur 40(α.4)` |
| 크기 9, 크림 `#FFFFBE` | 굵은 고딕 자막의 은은한 테두리광 | 1겹 `x0 y0 blur 9 α0.75` |
| "그림자 효과" 컬러 + 부드러움 27 | 대형 숫자 팝 | `x3 y3 blur 15` + `x0 y0 blur 28` |

**AE 크기/부드러움을 blur 에 그대로 넣지 말 것** — 9:16은 `ds ×1.78`이 붙는다. 실측 환산은 `blur ≈ AE값 / 1.78`, 그리고 "얼마나 퍼지나"가 아니라 "얼마나 진한가"로 번역해 겹을 쌓는다.

### 블러글로우(화이트 발광판) — 밝은 실사 위 대형 스토리 자막 (2026-08-19 신비감·AE 대조로 확정)

퍼포먼스 3존/스토리형의 **대형 본문 자막 표준**. AE의 복제-블러 기법(글자를 가우시안 블러 처리한 흰 덩어리를 뒤에 깔고 그 안에 텍스트가 앉음)을 text-shadow 겹쌓기로 재현한다.

```json
{"fontColor":"#141414","outlineColor":"#FFFFFF","outlineWidth":4,
 "textShadows":[
  {"color":"rgba(255,255,255,1)","x":0,"y":0,"blur":13},
  {"color":"rgba(255,255,255,1)","x":0,"y":0,"blur":13},
  {"color":"rgba(255,255,255,1)","x":0,"y":0,"blur":13},
  {"color":"rgba(255,255,255,0.95)","x":0,"y":0,"blur":26},
  {"color":"rgba(255,255,255,0.85)","x":0,"y":0,"blur":26},
  {"color":"rgba(255,255,255,0.55)","x":0,"y":0,"blur":42},
  {"color":"rgba(60,55,50,0.3)","x":5,"y":9,"blur":24}]}
```

- **핵심 = 같은 blur를 여러 겹 쌓기**: blur13 ×3이 글자 주변을 불투명한 흰 코어로 만들고, 26×2 → 42×1로 자연 감쇠. 딱 떨어지는 경계가 없어야 한다.
- **아웃라인은 3~4 (코어 채움 보조)** — 아웃라인을 키워서 흰 부분을 만들면 "흰 종이 스티커에 쓴 글자"가 되어 반려된다 (실측 3회 반려 끝에 확정). 흰 덩어리의 주인공은 어디까지나 블러 스택.
- 폰트는 명조/클래식 계열(국립박물관문화재단클래식B 검증) + 다크 채움 — 밝은 실사에서 흰 채움+검정 테는 싸 보인다.
- 강조어 run은 오렌지(#F5750E)류 단색 채움, 블러 스택은 entry 레벨 그대로 상속.
- 수치는 9:16(1080×1920) 자막 렌더 기준(fontSize 46 = 렌더 82px급). 다른 크기·포맷은 fontSize와 같은 비율로 blur/offset 스케일.
- 실측: 자막 16줄 소재에서 AE 레퍼런스와 질감 대조를 통과했다.

## 라벨 pill (소제목·카테고리 태그)

```
도형: backgroundColor rgb(0,0,0), backgroundOpacity 1,
      borderColor #FFFFFF, borderWidth 3.56, borderRadius 8.89   (z: 14)
텍스트: fontWeight 700, outlineWidth 0, 그라데이션 없음,
      크기는 본문 카피의 45~50% (예: 106.7 → 49.8)               (z: 15)
```
**⚠️ 배치는 절대좌표 손계산 금지 — 정석은 프레임 레이어 종속(flexbox)이다 (2026-08-19 유저 시연 역추출).** 에디터의 `type:"frame"` 레이어가 박스 비주얼(`shapeProps`: bg/보더/radius)과 레이아웃(`layoutProps`: direction/align/justify/padding/gap)을 담당하고, 텍스트는 `parentId`로 종속 + `positionMode:"flow"`로 넣으면 flexbox처럼 정중앙에 앉는다 (텍스트 y 손계산 금지). 에이전트 경로: `add_frame_layer`(box+layout) 후 반환 layer_id를 `add_text_layer`의 `parent_id`로 (2026-08-19 추가, E2E 검증). 자식 텍스트 width는 텍스트 실폭 이상으로(좁으면 줄바꿈돼 프레임을 넘친다). 상세 실물 구조는 story-format 스킬 반려 원칙 3번.

## 워크플로

1. **폰트 시안 보드** — 실무의 첫 단계. 같은 문구를 **폰트만 바꿔 3개** 세로로 배치하고 `preview_edit_frame` 한 번으로 비교 → 고른 것만 남기고 `delete_layer`. (채택된 폰트 시안 보드가 정확히 이 형태다. 흰색 반투명 패널 `opacity 0.8`을 대지로 깔면 폰트가 잘 보인다.)
2. **레시피 선택** — 골드/실버/모노 중. 소재 톤은 `get_frame_palette`의 `dominant`와 대조.
3. **적용** — `add_text_layer` 또는 `apply_edit_batch`.
4. **키워드만 다른 색이 필요하면 `runs`** — run의 concat이 `text`와 정확히 같아야 한다(서버 강제). run 단위로 `fontColor`·`fontGradient`·`fontWeight`를 줄 수 있어서 **숫자에만 골드**를 넣을 수 있다.
5. **QA** — `preview_edit_frame`로 눈 확인.

## 함정

- **`runs`와 `charAnimation`은 상호배타** — runs가 있으면 렌더러가 charAnimation을 무시한다
- **그라데이션 적용 후 `fontColor`만 보내면 그라데이션이 해제된다** (단색이 이김). 색만 바꾸려다 금속을 날리는 사고
- **폰트 크기는 포맷마다 다시 계산** — 렌더px = `fontSizeRatio × H² / 1080`. 9:16(H1920)은 ratio×3413, 16:9·1:1(H1080)은 ratio×1080. 위 실측값(106.7 / 88.9 / 49.8)은 **16:9 기준**이라 9:16에 그대로 쓰면 3배가 된다
- **그라데이션 텍스트에 filter 금지** — 렌더러가 `background-clip:text`로 그리는데 filter가 조상 어디에 있어도 깨진다. 아웃라인은 렌더러가 실루엣 링으로 따로 처리하니 `outlineWidth`만 주면 된다

## 감정 데코 자막 5종 (2026-08-27 전수 이식·실측)

상용 예능 데코 mogrt 팩 5종을 해체해 Jig 로 이식하고 실렌더까지 검증한 결과. **"화나는 자막", "무서운 자막", "설레는 자막" 같은 감정 지시가 오면 여기서 고른다.**

### 공통 구조 — 윗말(첨자) + 메인 2단

5종이 편집 슬롯까지 동일하다: `윗말 위치` / `윗말 내용` / `윗말 on·off` / `내용` / `효과 on·off`.

| | AE 원본(1920폭) | 9:16 Jig(1080폭) | fontSizeRatio |
|---|---|---|---|
| 윗말(첨자) | **45px 고정** | 25px | **0.0073** |
| 메인 | 95~118px | 66px | **0.0193** |

**윗말:메인 = 0.38~0.41.** 윗말은 메인 바로 위 한 줄, 살짝 왼쪽으로 치우쳐 앉는다(AE 실측 x=374 / 중앙 960 기준). 윗말은 **꺼도 되는 옵션**이지 필수가 아니다 — 한 소재에서 몇 개만 켜야 강조가 산다.

환산은 **폭 기준**이다: `Jig px = AE px × (1080/1920) = × 0.5625`. 높이 기준으로 환산하면 3배 커진다.

### 스토리형에서 부르는 법 — 등급을 먼저 정하고 온다

이 5종은 **한 소재에 전부 쓰는 세트가 아니라 배역 카탈로그**다. 스토리형에서는 `story-format` 의 감정 캐스팅 표에서 **등급을 먼저 정한 뒤** 여기로 온다:

| 등급 | 여기서 가져가는 것 | 넣는 곳 |
|---|---|---|
| **L2 배역** | **폰트 + 채움색 + 아웃라인 1겹**까지만 | `update_subtitle_entry.style` (자막 큐) |
| **L3 승격** | 전체 — 2중 테두리 + 글로우 + 데코 PNG | `add_text_fx_layer` (레이어, 타이밍 수동) |

**L2에서 2중 테두리를 시도하지 말 것** — 자막 큐 스키마에 `stroke2` 가 없어서 한 겹이 조용히 빠지고 납작해진다. 2중 테두리가 꼭 필요하면 L3로 올린다.

한 소재에 배역 폰트는 **2종까지**, L3는 **1~3개까지**. 5종을 다 꺼내면 소재가 아니라 폰트 견본이 된다.

### ⚠️ 도구부터 고른다 — 이건 `add_text_fx_layer` 의 일이다

이 자막들은 **채움 그라데 + 안쪽 획 + 바깥 획 + 글로우가 동시에** 걸린다. 일반 텍스트 레이어는 아웃라인이 1개뿐이고 `outlineWidth` 가 **글자 획을 파먹기** 때문에 절대 재현이 안 된다. 텍스트 2장을 겹치는 우회도 링이 뭉개진다.

**`add_text_fx_layer` 한 장이 정답이다** — `fillGradient` + `strokeColor/strokeWidth`(안쪽) + `stroke2Color/stroke2Width`(바깥, 2중 테두리) + `shadows`(글로우 스택)를 전부 동시에 받는다. `strokeWidth` 는 **글자 밖으로만 그려져 획을 안 먹는다.**

> **2026-08-27 실패**: 이 도구를 두고 일반 텍스트 레이어로 만들다가 그라데가 죽고 테두리가 뭉개져 반려됐다. 방송 자막·팝 자막은 무조건 textFx로 시작할 것.

### 안→밖 순서는 테마마다 다르다 — 반드시 단면을 스캔한다

AE 실렌더를 픽셀로 가로 스캔한 결과(바깥 → 안, comp 1920 / 폰트 110~118px 기준):

| 테마 | 바깥 | 중간 | 채움 |
|---|---|---|---|
| **금빛** | **흰 2px** | 갈색 3px | 금 그라데 |
| **분노** | **진빨강 3px** | 흰 3px | 주황 그라데 |
| **러블리** | **핑크 4px** | 흰 4px | 마젠타 |
| **우울** | 흰 소프트 글로우 ~5px | — | 차콜 |
| **공포** | 붉은 글로우만 | — | 흰색 |

**금빛은 흰색이 바깥, 분노·러블리는 흰색이 안쪽이다.** 아래 레시피 표의 stroke/stroke2 순서를 그대로 따른다.

### 5종 레시피 — Jig 실적용값 (9:16, 렌더 검증 완료)

`add_text_fx_layer` 의 `fx` 에 그대로 넣는 값이다. `fontSize` 는 에디터 px(렌더 = px × H/1080).

| 테마 | 폰트 | fontSize | fill | strokeColor/Width | stroke2Color/Width |
|---|---|---|---|---|---|
| **금빛** | `PyeongChangPeace-Bold` | 52 | 그라데 `#FEFEF0 0 / #F8EC7A 37 / #FFD467 61 / #FFB055 100` | `#864C07` 4 | `#FFFFFF` 5.5 |
| **공포** | `FUNFLOW-SURVIVOR-KR` | 48 | `#FFFFFF` | — | — |
| **러블리** | `RoomNo703` | 48 | `#F01D7F` | `#FFFFFF` 3.4 | `#FF87A6` 6.8 |
| **분노** | `Tenada` | 51 | 그라데 `#E30000 0 / #EC3417 35 / #F4672F 62 / #FC9C4B 100` | `#FFFFFF` 2.6 | `#9E0000` 6.5 |
| **우울** | `EF_제주돌담체(OTF)` | 42 | `#474747` | `#FFFFFF` 2.2 | — |

`shadows` 는 두 테마만:
- **공포** `#900D0D` b6 → `#900D0D` b14 → `rgba(129,7,7,.9)` b30 → `rgba(69,6,6,.7)` b55

**윗말(첨자)** 은 `fontSize 20` 에 같은 처리의 축소판(획 폭 ~절반), `textAlign: left` 로 메인 왼쪽 위에 붙인다.

### 데코 PNG 없이는 다른 물건이다

5종 전부 좌우에 데코가 붙고, 이게 감정 신호의 절반이다. **원본 팩의 PNG 는 재배포하지 않는다** — 라이선스 확인된 에셋이나 직접 만든 스티커(`design-corpus` 의 svg 패스)로 대체한다. 원본 크기 / AE scale:

| 테마 | 에셋 | 크기 |
|---|---|---|
| 금빛 | 반짝이 ×2 | 51×62, 48×64 |
| 공포 | 연기 ×2 | 428×293 (화면 밖으로 흘림) |
| 러블리 | 하트 ×1 | 85×69 (우측 끝) |
| 분노 | 불꽃 대/소 | 218×300 @65%, 93×129 @100% |
| 우울 | 물방울 ×2 | 63×127, 67×127 @60% |

크기는 **자막 글자 높이 대비 비율로 잡는다** (불꽃 = 글자의 1.7배). AE 절대좌표를 그대로 환산하면 폰트를 키운 순간 어긋난다.

### ⚠️ 데코가 글자를 덮으면 `zIndex` 를 명시한다

`add_layer` 로 나중에 추가한 이미지가 텍스트 위로 올라온다. **배열 순서를 바꾸는 것만으로는 안 되고, 각 레이어의 `zIndex` 를 명시적으로 써야 렌더러가 따른다** (실측: 배열만 재정렬했을 땐 연기가 계속 글자를 덮었고, `zIndex` 를 순번대로 박으니 즉시 뒤로 갔다). 데코 < 텍스트 순으로.

### 폰트 = 감정 연기, 5종 실증

같은 제작사가 같은 날 만든 5종이 **전부 다른 폰트를 쓴다.** 색만 바꾸고 폰트를 돌려쓰지 않았다는 뜻이다 — 폰트 캐스팅이 감정 연출의 1순위라는 증거.

`금빛=평창평화체(각지고 반듯)` · `공포=펀플로 생존자(거칠고 불안정)` · `러블리=Room No.703(둥근 손글씨)` · `분노=Tenada(초굵은 임팩트)` · `우울=제주돌담체(성글고 힘없음)`

**평창평화체는 ㅇ·ㅁ 속공간에 다이아 모티프가 폰트 자체에 들어 있다.** 반짝이 데코를 따로 얹은 게 아니다 — 확대해서 확인함. 금빛 룩의 절반은 이 폰트가 만든다.

### 함정 — run에 `fontColor`를 주면 entry 레벨 그림자가 상속되지 않는다

`add_text_layer` / `update_text_layer` 의 최상위 `text`·`patch` 에는 **`textShadows` 필드가 아예 없다.** 글로우 스택은 `runs[].textShadows` 로만 넣을 수 있고, run에 `fontColor` 를 주는 순간 entry 레벨 스타일 상속이 끊긴다. 그래서 **run마다 `fontColor` + `outlineColor` + `outlineWidth` + `textShadows` 를 전부 직접 써야 한다.** 하나라도 빼면 그 속성만 조용히 사라진다.

배치(`apply_edit_batch`)의 `add_layer` → `text_props` 에도 runs·shadow가 없다. **2패스가 정석**: ①`add_layer`로 텍스트·폰트·크기·정렬만 올리고 ②`update_text_layer` patch로 runs를 입힌다.

### 임플란트 광고 예능 자막 재구성 (2026-07-31)

임플란트 소재를 예능 자막으로 재구성. 훅 추가 + 골드 중앙 강조 + 실버 강등의 3단 위계.

| 요소 | 레시피 | 값 |
|---|---|---|
| 훅 `왜 이렇게 비쌀까?` | 모노 | `국립박물관문화재단클래식B`, ratio 0.0926(=100px), outline 5 |
| 라벨 pill `1개든 10개든` | pill | ratio 0.0426(=46px), 도형 z14 / 텍스트 z15 |
| 강조 `20만원` | 골드 | ratio 0.1481(=160px), outline 8 |
| 설명 `국산 정품 임플란트` | **흰 단색** | ratio 0.0648(=70px), outline 3.5 |

배운 것 2개:

1. **금속을 3개 쌓지 않으려면 하나를 단색으로 강등한다.** 원본은 골드+실버 2개였는데 훅(모노)을 추가하면 3개가 된다. 설명 텍스트의 실버를 흰 단색 + 검정 아웃라인으로 낮추니 위계가 살아났다 — 금속을 뺀 게 아니라 **강조 순위가 낮은 것부터 금속을 회수**하는 순서.
2. **정렬 축은 하나로.** 훅·골드·설명은 중앙인데 pill만 좌측이라 시선이 지그재그였다. pill을 중앙(x = 0.5 − w/2)으로 옮기자 바로 정리됨. 축이 섞이면 요소가 아무리 예뻐도 산만해 보인다.

### 유퀴즈풍 자막 정본 케이스 (2026-08-21)

유퀴즈풍 자막의 **정본 케이스**. 원본 클립 4개를 재생성 없이 업로드해 조립하고, 자막 스타일 + 텍스트 인터랙션 2종(키워드 팝 `5만건`, 조립형 3단)을 얹었다. 32초 9:16.

배운 것 3개:

1. **"유퀴즈 자막"은 화면에서 제일 큰 글씨가 아니다.** 처음에 상단 헤드라인(라임+검정테)을 유퀴즈 자막으로 착각해 반려됐다. 유퀴즈 자막은 **영상 위 좌측 하단의 손글씨**고, 헤드라인은 별개 요소다.
2. **자막만 옮기면 절반이다** — 팝/조립을 빼먹고 "왜 아무것도 안 했냐"는 지적을 받았다. 스토리형이면 팝/조립 레이어를 반드시 넣는다.

### 밀도 높은 유퀴즈 소재 (2026-08-21)

**밀도 높은 유퀴즈 소재의 정본 케이스.** 39초에 자막 11줄 + 인터랙션 3계열(카운트업 / 누적 2단 / 세로 2단 + 팝). 메인 컴프 1080×1920 안에 `가로` 컴프가 57%로 들어간 구조라 좌표·크기를 전부 환산했다.

배운 것 3개:

1. **폰트 11줄에 11종.** 이게 이 문법의 뼈대다 — 한 폰트로 통일하면 스타일을 아무리 얹어도 유퀴즈가 안 된다.
2. **컬러 외부광선이 손글씨 자막의 시그니처**(크기 52, 파랑/빨강/마젠타를 대사마다 교체). 굵은 고딕 자막에는 크림 `#FFFFBE` 크기 9의 은은한 테두리광만 얹는다.
3. **폰트 6종을 대체해야 했다** — 5종은 미설치, 2종은 Adobe Fonts라 업로드 불가(라이선스). AE에 폰트명이 있다고 설치돼 있다는 뜻이 아니다.

### 텀블러 8초 숏츠 "12 HOURS LATER / STILL HOT." (2026-08-29)

textFx + 다중그림자 이식 후 첫 실전. 다크 배경 텀블러 2컷(물붓기→리프트), 영문 카피.

| 요소 | 레시피 | 값 |
|---|---|---|
| 훅 `12 HOURS LATER` | 모노 그라데 + textShadows(회색 글로우+검정 소프트) | ratio 0.0164, outline 1.6, 0ms 무모션 |
| 팝 `STILL` / `HOT.` | **textFx** 골드 4-stop + 검정획9 + 흰2차획15 + 하드섀도 스택 + roughen(3/0.08) + skew −5 | fontSize 104, slideUp+spring+distancePx 620, 스태거 480/700 |
| CTA `LINK IN BIO` | 골드 보더 pill 프레임 종속 + **단색 골드** 텍스트 | 75% 지점(6060ms) bounce |

배운 것 3개:
1. **그라데이션 텍스트는 프레임(flexbox) 자식으로 넣으면 센터링이 어긋난다** — fontGradient 가 SvgRichText 경로를 타서 flex 폭 계산과 어긋남. 프레임 자식 텍스트는 단색으로 (골드 과다 방지 강등과도 맞아떨어짐).
2. **`clip-framing` 은 통짜 덮어쓰기** — transition 만 바꿔 보내면 grade/freeze/endScale 이 전부 날아간다. 항상 전체 값 재전송.
3. **freeze 필드는 snake_case** (`at_ms`/`hold_ms`/`punch_release`). whip 전환은 정지컷 경계에서 미러 잔상처럼 보일 수 있어 flash 160ms 가 안전.
4. **(사용자 반려로 교정) textFx 2차(흰) 스트로크는 fontSize 의 ~7%가 상한** — 15/104(14%)는 "초딩 스티커" 판정. 최종 채택값: stroke 5 + stroke2 7 @ fontSize 96. 그리고 **여러 줄 팝은 textFx 한 장에 `\n`으로** — 줄마다 레이어를 나누면 흰 테 두 덩어리가 겹쳐 뭉개진다. 섀도도 하드 1 + 소프트 1이면 충분.

## QA 체크리스트

- [ ] 금속 그라데이션에 **중간 흰색 stop**이 있는가 (없으면 그냥 노란/회색 글씨)
- [ ] 아웃라인이 fontSize의 4~6%인가
- [ ] 금속 텍스트가 골드 1 + 실버 1 이내인가
- [ ] 라벨 pill의 텍스트 z가 도형보다 위인가
- [ ] 포맷에 맞는 fontSize로 재계산했는가 (16:9 값을 9:16에 그대로 안 썼는가)
- [ ] 밝은 배경에 흰 글씨 + 흰 그림자가 겹치지 않는가
- [ ] **스토리형인데 자막만 있고 팝/조립 레이어가 0개는 아닌가** — 대사가 20초 넘는데 인터랙션이 하나도 없으면 자막 영상이지 광고가 아니다
- [ ] 조립형 구간의 **대사 자막을 지웠는가** (같은 문구 2회 노출 금지)

- [ ] 카운트업 겹침 레이어에 불투명도 0.6을 줬는가 (불투명하면 오타로 보인다)
