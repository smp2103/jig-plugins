# 예능형 자막 문법 (방송 자막 스타일)

출처: 방송형 광고 AE 원본(대담형) 전수 추출 + Jig 재현 검증 (2026-08-16). 수치는 전부 실측.

## 0. 일반화 레이어 — 케이스 복사 금지 (2026-08-17, 실전 반려로 추가)

**아래 §1~§5의 구체 수치(골드/민트 스탑, 폰트 배역, 카피)는 "대담형 사례 케이스"다. 새 소재에 그대로 옮기면 복사지 응용이 아니다** — 실전에서 정확히 이걸로 반려당했다. 새 소재는 다음 순서로 캐스팅한다:

1. **스킴 유도** (`get_frame_palette` / `get_color_scheme`, ad-brand 스킬 references/genre-recipes.md §2): 8토큰 + accent 1개 + avoid 규칙. **테두리색도 순검정 대신 스킴의 딥 톤**(딥브라운/딥네이비)을 검토.
2. **그라데이션은 공식으로 생성, 값 복사 금지**:
   - 금속 광택 = **중간 흰색 stop이 핵심** (variety-caption-style 스킬 실측 — 흰 stop 없으면 그냥 색 글씨). 골드: 색→흰→색→어두운색 4단. 실버: 흰 stop 2개로 넓은 하이라이트 띠.
   - 단순 입체 = 밝은 상단→어두운 하단 2~4단 (대담형 사례 계보 — 흰 stop 없음, 더 플랫한 예능 결).
   - 색상은 스킴/브랜드에서 파생: accent 또는 지배색의 명도 변주로 stop을 만든다.
3. **금속 위계**: 한 화면 골드 1 + 실버 1 이내. 3개째부터는 **강조 순위 낮은 것부터 단색+테두리로 강등** (variety-caption-style 케이스 로그 실측).
4. **폰트 캐스팅**: 감정→폰트는 §1 표를 "후보군"으로만 쓰고, variety-caption-style 폰트군(제주돌담/WILDgag/Cafe24 계열/국립박물관클래식)과 **감정 데코 5배역**(아래), 전역 카탈로그(`list_project_fonts`, 99종)에서 **소재마다 새로 캐스팅**한다.

   **감정 데코 5배역** (2026-08-27 상용 예능 데코 팩 이식 — 방송 제작사가 같은 날 5개 감정에 배정한 실제 캐스팅. 레시피 전문은 `variety-caption-style` "감정 데코 자막 5종"):

   | 감정 | 폰트 | 획 구조 |
   |---|---|---|
   | 부/성취 | `PyeongChangPeace-Bold` | 금 그라데 + 갈색 안쪽 + 흰 바깥 |
   | 공포/긴장 | `FUNFLOW-SURVIVOR-KR` | 흰 채움 + 붉은 글로우 4단 |
   | 애정/설렘 | `RoomNo703` | 마젠타 + 흰 안쪽 + 핑크 바깥 |
   | 분노/흥분 | `Tenada` | 주황 그라데 + 흰 안쪽 + 진빨강 바깥 |
   | 우울/체념 | `EF_제주돌담체(OTF)` | 차콜 채움 + 흰 소프트 글로우 |

   **가져다 쓰는 게 아니라 문법을 쓰는 것이다.** 문구·길이·배경이 다르면 크기와 데코 좌표는 전부 다시 잡아야 하고(실측: 폰트를 키우자 불꽃 위치가 통째로 어긋났다), **데코 PNG와 폰트는 원본 팩의 자산이라 그대로 재배포하지 않는다** — 실제 소재에는 라이선스 확인된 에셋으로 대체할 것. 같은 감정이라도 배역을 바꿔야 소재가 달라 보인다. 확신 없으면 폰트 시안 보드(같은 문구 × 폰트 3종) 먼저.
5. **기법은 문법이라 재사용 OK**: 조각유지, 조립형 슬라인, 당황 세로줄, 흰 글로우 잉크, 칩, 팝 textFx — 이건 "언제 쓰나"(트리거)가 본질이고 색·폰트가 정체성이 아니다.

| 트리거 (대사 상황) | 기법 |
|---|---|
| 킬러 숫자/가격이 뒤늦게 등장 | 조립형 레이어 + slideRight spring distancePx 600~1000 (§3.3) |
| 나열·단계 강조 (첫번째/두번째) | 조각유지 + 라벨 칩 바운스 (§5) |
| 당황·민망·자조 | 세로줄 마크 (§3.5) + 회상 결 폰트 |
| 경고·반전 ("~하면 안 돼요") | 박스 없는 어두운 잉크 + 흰 글로우 (§2.7) |
| 리액션 폭발 | textFx 팝 (§3) |

6. **스토리형의 척추는 발화하는 인물이다** (2026-08-17 실전 반려로 추가): 무성 b-roll + 외부 나레이터로만 구성하면 자막·음성·영상 싱크가 없어 어색하다. 인물 등장 씬은 `generate_video`의 `dialogue`(한국어 대사 → 립싱크+음성 생성)로 만들고, 자막은 발화의 압축·강조로 그 발화 시점에 물린다. 나레이터는 브릿지용 최소로.

7. **dialogue 프롬프트에 한숨·망설임 연기를 시키지 말 것** (2026-08-17 반려 — 정석은 생성 단계 원천 차단): 프롬프트에 "small sigh", "resigned shrug", "pause" 같은 지시를 넣으면 **그대로 생성돼** 한숨·늘어짐이 클립에 박히고, 이건 가청음이라 무음 검출도 비껴간다. 감정은 표정·톤 형용사로만 주고, 발화 지시는 이 표준 문구를 붙인다: *"delivers the line immediately and continuously — no sighing, no long pauses, no filler sounds — and stops right after finishing the line."* 이미 생성된 클립의 한숨은 재생성이 정석이고, 점프컷 분할(§타임라인 밀도)은 재생성이 아까울 때의 폴백이다.

## 2. 하우스 스택 공식 (AE 원본 레이어 스타일 실측)

강조 자막 한 줄 = 최대 6겹. per-entry style로:

```json
{
  "fontFamily": "SDGaehwa-aRg",
  "fontGradient": {"angleDeg": 180, "stops": [{"color": "#FFF2B8", "offset": 0}, {"color": "#FFD966", "offset": 45}, {"color": "#D9A430", "offset": 75}, {"color": "#9C7018", "offset": 100}]},
  "outlineColor": "#000000", "outlineWidth": 4,
  "textShadows": [
    {"color": "rgba(255,255,255,0.65)", "x": 0, "y": 1, "blur": 7},
    {"color": "#000000", "x": 2, "y": 2, "blur": 0},
    {"color": "#000000", "x": 3, "y": 3, "blur": 0}
  ],
  "backgroundOpacity": 0
}
```

- `textShadows[]` = 다중 그림자 스택(위→아래 순). **흰 헤일로 1겹 + 검정 하드섀도(blur 0) 2겹**이 표준. 있으면 단일 shadow* 필드는 무시됨.
- 그라데이션 관례: 밝은 상단 → 어두운 하단 (angleDeg 180). 민트 글로우가 필요한 줄은 헤일로를 `{"color":"rgba(28,228,174,0.8)","x":0,"y":0,"blur":9}`로.
- **아웃라인 캘리브레이션: 3~5가 정답.** 12는 검은 덩어리가 되고, 어두운 배경 위에선 "안 나온다"로 오판하게 됨.
- `edgeRoughen: {"scale": 2~5, "freq": 0.06~0.11, "seed": 고정}` = 분필/찢김 질감(AE 가장자리 거칠게). 시드 고정이라 프레임간 결정적.
- 그라데이션·edgeRoughen이 있는 자막/텍스트는 렌더러가 자동으로 **SvgRichText**(SVG 경로)로 그림 — 진짜 바깥 스트로크, bg-clip 함정 없음. 자동 줄바꿈이 없으므로 **명시적 \n 필수**.
- 키워드 부분 강조는 runs — §2.5 참조. **한 줄 안에서 색이 갈리는 원본은 엔트리 분할이 아니라 runs가 정답.**

## 2.5 runs — 부분 자막 스타일 (한 줄 안에서 갈아끼우기)

에펙 원본은 한 자막 안에서 characterRange 단위로 폰트·색·테가 갈린다 (원본 덤프가 그 증거). Jig도 `update_subtitle_entry`의 `runs[]`로 동일하게 재현한다. 텍스트는 runs의 text 연결로 대체되므로 **줄바꿈 \n 도 run text 안에 포함**시킬 것.

run별 지원 필드 (전부 entry 스타일 override):
- `fontFamily` `fontSize`(에디터px) `fontWeight` `fontStyle`("italic") `letterSpacing` `textDecoration`
- `fontColor` 또는 `fontGradient` (run별 그라데이션 가능)
- `outlineColor` / `outlineWidth` — **run별 테두리 색·두께** (진짜 바깥 스트로크, SVG paint-order)
- `textShadows[]` — run별 그림자 스택 (없으면 entry의 스택 상속)

검증 스펙 (대담형 사례 "맞춤 제작포함한 가격이 **20만원**" — 골드런+검정테 / 민트런+딥틸테 공존):

```json
{"runs": [
  {"text": "맞춤 제작포함한 가격이 ", "fontFamily": "SDNemony2dBasicBd", "fontSize": 36,
   "fontGradient": {"angleDeg": 180, "stops": [{"color": "#FFE98A", "offset": 0}, {"color": "#FFD649", "offset": 45}, {"color": "#D9A430", "offset": 100}]},
   "outlineColor": "#000000", "outlineWidth": 4},
  {"text": "20만원", "fontFamily": "SDNemony2eBasicHv", "fontSize": 52, "fontStyle": "italic",
   "fontGradient": {"angleDeg": 180, "stops": [{"color": "#66F5D0", "offset": 0}, {"color": "#1E9588", "offset": 55}, {"color": "#0C6152", "offset": 100}]},
   "outlineColor": "#0D5245", "outlineWidth": 4}
]}
```

주의:
- run에 `fontGradient`/`outlineWidth`/`textShadows`가 하나라도 있으면 그 엔트리는 SvgRichText 경로로 그려짐 → 자동 줄바꿈 없음, **명시적 \n 필수**.
- `edgeRoughen`은 **entry 단위만** 가능 (SVG 필터가 tspan에 안 붙음). run별 거칠기가 필요하면 엔트리를 분할하거나 textFx 레이어로.
- 민트 계열 run의 테는 검정 대신 딥틸(#0D5245)이 원본 관례 — 검정테는 민트를 죽인다.

## 2.7 어두운 잉크 + 흰 글로우 (박스 없는 차분 강조) — "가격만 보시면 안 돼요" 검증

경고/차분 강조 대사의 원본 문법은 박스가 아니라 **흰 외부광선이 가독성 판** 역할 (AE: glow 크기35 42% + 흰 소프트섀도 크기21 63%). 박스를 깔면 원본과 달라지고, 여기에 두꺼운 테두리까지 얹으면 뭉개진다.

```json
{
  "style": {
    "fontFamily": "WarhavenB", "fontSize": 30, "backgroundOpacity": 0,
    "outlineWidth": 0, "letterSpacing": -0.5,
    "textShadows": [
      {"color": "rgba(255,255,255,0.9)", "x": 0, "y": 0, "blur": 4},
      {"color": "rgba(255,255,255,0.75)", "x": 0, "y": 0, "blur": 10},
      {"color": "rgba(255,255,255,0.75)", "x": 0, "y": 0, "blur": 10},
      {"color": "rgba(255,255,255,0.55)", "x": 0, "y": 2, "blur": 18},
      {"color": "rgba(255,255,255,0.55)", "x": 0, "y": 2, "blur": 18},
      {"color": "#000000", "x": 1, "y": 1, "blur": 0},
      {"color": "#000000", "x": 2, "y": 2, "blur": 0}
    ]
  },
  "runs": [
    {"text": "가격", "fontSize": 46, "fontColor": "#929292", "outlineColor": "#000000", "outlineWidth": 1.5},
    {"text": "만 보시면 안 돼요", "fontSize": 30, "fontColor": "#1F1E1E", "outlineColor": "#000000", "outlineWidth": 1}
  ]
}
```

- **키워드만 1.55배 + 회색(#929292), 본문 #1F1E1E** — AE 원본은 레이어 2장(155%/100% 스케일), Jig 는 runs 크기 차등으로 동일 재현 (베이스라인 자동 정렬).
- **CSS/SVG 그림자는 AE 글로우보다 얇다** — 같은 겹을 2번 반복해 누적(위 스택처럼)해야 판이 생긴다. 1겹 blur 12 로는 어두운 배경에서 안 읽힘 (실측).
- **테두리 캘리브레이션 주의**: AE layer-style stroke "크기 3" 은 소스px(87pt 글자 기준) → 렌더 환산 1~3px 의 은은한 선. 에디터 outline 환산은 가격 1.5 / 본문 1. **outline 3~5 는 그라데이션 대형 자막 전용** — 박스 위나 일반 크기 대사에 쓰면 렌더 5px+ 가 되어 가는 획 폰트(WarhavenB 등)를 잡아먹는다.
- 하드 블랙 섀도도 이 급에선 (1,1)(2,2) — 하우스 스택의 (2,2)(3,3) 는 대형 자막 기준.

## 3. 팝 자막 (textFx 라이브 레이어)

"아니에요!"류 회전 팝은 **자막이 아니라 textFx 레이어** — 원본 AE도 별도 레이어다. 본문(회색 무테 자막)과 분리해야 entry 아웃라인이 본문을 오염하지 않는다.

`add_text_fx_layer` 검증 스펙 (아니에요!):

```json
{
  "x": 0.44, "y": 0.50, "width": 0.52, "height": 0.14, "rotation": -4, "z_index": 45,
  "fx": {
    "text": "아니에요!", "fontFamily": "SDCrack", "fontSize": 72, "letterSpacing": 1,
    "fillGradient": {"angleDeg": 180, "stops": [{"color": "#F04030", "offset": 0}, {"color": "#C81A1A", "offset": 40}, {"color": "#7A0808", "offset": 75}, {"color": "#3D0202", "offset": 100}]},
    "strokeColor": "#FFFFFF", "strokeWidth": 7,
    "shadows": [{"color": "#000000", "x": 4, "y": 5, "blur": 0}],
    "roughen": {"scale": 3.5, "freq": 0.06, "seed": 7}
  }
}
```

- 수정은 `update_text_fx_layer` — fx는 **merge**(바꿀 키만), 텍스트·크기·색·질감 즉시 반영 (재베이크 없음).
- 이중 테는 stroke2Color/stroke2Width. 등장 모션은 레이어 motion(bounce 등) — 원본도 통짜 바운스.
- 자동 줄바꿈 없음(명시 \n), 글자별 애니는 미지원(레이어 모션만).

## 3.3 조립형 대사 — 문장 일부가 따로 날아드는 연출 ("맞춤 제작포함한 가격이 + 20만원" 검증)

원본 AE 에서 한 문장의 일부(가격 등 킬러 워드)가 **별도 레이어로 뒤늦게 슬라이드인**하는 구성은 자막 entry 하나(runs)로 만들면 안 된다 — entry 는 통째로 갱신되어 먼저 나온 부분까지 다시 팝하고, 부분 모션이 불가능하다. **텍스트 레이어 2장으로 분리**가 정답:

- 문장부: `add_text_layer` + `motion.enter {type:'slideUp', durationMs:550, easing:'spring', distancePx:550}` (AE 원본도 아래서 +900 바운스업 — 렌더 환산 ×0.61).
- 킬러 워드: 뒤 타이밍에 `motion.enter {type:'slideRight', durationMs:500, easing:'spring', distancePx:900}` — **slideRight = 왼쪽에서 진입**. 원본 Motion Controls Position 오프셋 [-1400,0] → distancePx ≈ |오프셋|×중첩스케일.
- `distancePx` 는 슬라이드 이동 거리(출력 px, 기본 60/80). **예능식 화면 밖 훅 인은 600~1000 + spring** — 오버슈트 착지가 자동으로 생긴다.
- 해당 자막 entry 는 삭제 (내림차순). 레이어 배치는 원래 한 줄 합성 위치를 그대로 쪼개서 (문장 좌측 x~0.09, 킬러 워드 x~0.615, 동일 y) 넣으면 정지 상태가 기존과 동일.
- 레이어 textShadows 는 add 스펙에 없음 → add 후 text-layer patch 로 하우스 스택 주입.
- **박스 치수 함정 (실측)**: 에디터의 텍스트 자동 높이는 top 고정·DOM 줄바꿈 기준으로 박스 높이를 다시 쓴다. ① 높이는 처음부터 콘텐츠 높이(글리프 렌더px × lineHeight ≈ fontSize×ds×1.35)로 정확히 — 넉넉히 잡으면 에디터가 줄이거나 키우면서 verticalAlign middle 기준 세로 정렬이 깨진다. ② SVG 텍스트(그라데이션/run장식)는 렌더에서 안 감기지만 **측정기는 DOM 줄바꿈으로 잰다** — 박스 폭이 한 줄 폭보다 좁으면 2줄로 측정돼 박스가 커짐. 폭은 반드시 한 줄 폭 + 여유로.
- 두 레이어 세로 정렬은 "텍스트 중심 y 통일"로 계산: y = 목표중심 − 콘텐츠높이/2.

## 3.5 감정 장식 마크 (당황 세로줄)

당황·민망 대사 옆에 만화식 세로줄 3개를 좌우 대칭으로 드리움 (AE 원본: 검정 얇은 수직선 3~4개 × 좌우, 높이 스태거, 회전 없음). **텍스트 글리프(|,│)로 흉내내지 말 것** — 회전하면 대각 점선로 붕괴(실측 실패). 정답은 **얇은 shape rect 6장**: 폭 0.004, 높이 0.034/0.044/0.037 스태거, y 0.522~0.540 스태거, 간격 x 0.017, 자막 양 어깨 바로 바깥(좌 x 0.228~0.262 / 우 0.734~0.768, marginV 700 자막 기준), `#111111` op 0.92 radius 2, enter fade 180ms + delayMs 0/60/120 스태거. 해당 대사 자막은 흰→회 금속 그라데이션(#FFFFFF→#D9D9D9→#8E8E8E)이 관례.

## 4. 크기 환산 (렌더 폰트 공식) + 포맷별 크기 스펙

렌더px = 에디터px × H/1080, 에디터px = fontSizeRatio × H.
- 자막: 원하는 렌더px → `fontSizeRatio = px × 1080 / H²`. 9:16(H1920) 기본 대사 53px → 0.0155, 강조 77px → 0.0225.
- runs/textFx의 fontSize는 에디터px 단위 (9:16에서 렌더의 ÷1.78).

### 포맷별 크기 스펙 (2026-08-17 "폰트 작다·여백 많다" 반려 → AE 원본 실측으로 확정)

원본 실측(9:16 최종 화면): **헤드라인 93px(폭 = 화면 80%)**, CTA 63px, 강조자막 53~82px, 주석 25px. 작아 보이는 주범은 자막이 아니라 **헤드라인/CTA/주석이 한 단계씩 작을 때** — 상단 존이 비면서 전체가 성겨 보인다.

| 요소 (렌더px) | 9:16 (ratio) | 16:9 | 1:1 |
|---|---|---|---|
| 상단 헤드라인 본문 | **90** (0.0264) | 76~84 | 80~88 |
| 헤드라인 킬러워드 run | 110 (ed 62) | 92 | 100 |
| 강조 자막 | 77~80 (0.0225) | 60~66 | 64~70 |
| 조립형 빅넘버 | 105~110 (0.031~0.032) | 92~100 | 96~105 |
| CTA | 63 (0.0185) | 54 | 56 |
| 기본 대사 | 53 (0.0155) | 44 | 46 |
| AI 주석 | 25 (0.0073) | 22 | 22 |

- 크기 올린 뒤엔 **줄바꿈·겹침 재검증 필수** (박스 폭 = 한 줄 폭 + 여유, 조립형은 문장/숫자 박스 경계 재계산).
- 헤드라인 2줄이 화면폭 80~90%를 채워야 원본 밀도가 나온다.

## 5. 화자별 스타일 배치 (대담형)

- 포맷 기본 스타일 = 최다 빈도 스타일(검정박스 흰 고딕)로 잡고, 강조 줄만 per-entry override.
- 검정박스: `backgroundColor #0E0E0E, backgroundOpacity 1, radius 0`. 강조형: `backgroundOpacity 0` + 스택.
- **진행형 자막(줄 누적)은 조각 유지(piece-persist) — 절대 앞 줄을 뒤 엔트리에 중복 포함하지 말 것.** "사후관리까지" → "사후관리까지\n책임지는지 확인" 식 엔트리 교체는 금지: 같은 대사가 두 엔트리에 존재해 전환 시 줄이 튀거나 겹쳐 이중 렌더된다 (사람 편집자는 이렇게 안 한다, 실측 반려). 정답: 줄1 엔트리를 끝까지 연장하고(윗줄 박스 `editor: {y:0.501, height:0.0583}`), 줄2는 자기 텍스트만 가진 별도 엔트리(아랫줄 박스 `y:0.5594`)로 추가. AE 원본도 줄마다 별도 레이어다. 엔트리 박스는 `update_subtitle_entry`의 `editor` 패치(정규화 0~1)로 지정.
- 안내 배너: 남색 `#232B66` + radius 14 + runs 볼드 강조 + ▼는 runs로 `{"text":"▼","fontColor":"#FFD84D"}`.
