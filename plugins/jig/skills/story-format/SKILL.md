# 스토리형 소재 제작

스토리형 = **여러 영상 클립을 시퀀스로 붙이고 + TTS 나레이션 + 예능형 자막**을 입히는 소재.
"인물이 카메라 보고 대사 한 번"형과 다르다.

## 전제

- 작업 중 사람이 같은 draft 를 jig.ai.kr 편집기에 열어두지 않게 한다 — 자동저장이 에이전트 변경을 덮어쓴다.
- 이 스킬의 모든 절차는 Jig 도구만으로 된다. 막히면 "방법이 틀린 것"이지 환경 탓이 아니다.

## 구조 문법 (2종)

**나레이션형**: ① 훅 카드 0~5초(before/after 이미지 + 타이틀 텍스트 레이어, TTS 없음) → ② 클립 시퀀스 + TTS 나레이션(나레이션 시작 시점부터 자막 정합) → ③ CTA 자막.
자막은 단일 스타일(굵은 한글 + 검정 아웃라인, 중앙 밴드), 키워드만 runs 컬러.

**대담형**: 3존 레터박스 — 상단 헤드라인 존(키워드 runs 컬러) / 중앙 16:9 영상 / 하단 CTA 존.
자막은 **화자별 멀티 스타일**: 질문자 = 검정 박스 + 흰 고딕, 답변 강조 = 예능형 스택. 라벨 칩(첫번째/두번째)은 별도 텍스트 레이어.
- 중앙 영상을 존 크기로 줄이는 클립 박스 배치는 편집기에서 사람이 클립 박스를 조정해야 한다. `set_clip_framing` 은 **콘텐츠 줌·팬 전용**이라 존 배치용이 아니다(쓰면 영상이 크롭돼 1:1 처럼 보인다). 사람 손을 못 빌리면 **풀블리드 설계**로 간다.

두 유형 공통: 키프레임 모션을 욕심내지 않는다. 타이밍 × 스타일 밀도로 승부하고, 등장 바운스 정도만 레이어 motion 으로.

## 예능형 자막

핵심 문법 전체는 `references/variety-captions.md` — **폰트 갈아끼우기(폰트 = 감정 연기), 하우스 스택 공식(테 + 헤일로 + 하드섀도 + 그라데이션), textFx 팝 자막, 크기 환산**. 자막 디자인 전에 반드시 읽는다. 룩 레시피는 `variety-caption-style` 스킬.

## 톤 디폴트 — 지시가 없으면 퍼포먼스 3존

기획서의 비주얼 무드("프리미엄 에디토리얼", "시네마틱")는 **이미지 생성용 지시이지 편집 스타일 지시가 아니다.** 스타일 지시가 따로 없으면 기본은 퍼포먼스 3존 레터박스다.
- 상단 검정 후킹 밴드(흰 서브카피 1줄 + 옐로 볼드 헤드라인 1줄)
- 중앙 영상 존 + **대형 자막** — 밝은 실사 위에서는 다크 채움 + **블러글로우(흰 발광판)**. 레시피 정본은 `variety-caption-style` "블러글로우". 아웃라인을 키워 흰 부분을 만들면 "흰 스티커에 쓴 글자"가 되어 반려된다.
- 하단 브랜드 밴드는 **기획서에 브랜드/CTA 존 지시가 있을 때만.** 자막 중심 기획이면 밴드 없이 자막만. 의료/시술 광고면 최하단 고지 스트립("개인에 따라 차이가…" + AI 고지)은 항상.

대담형 예능 자막 두께 검증값: 1080 캔버스 43px + **outlineWidth 4** + 아웃라인은 순검정 대신 스킴 다크(#1A0D09류) + textShadows [흰 헤일로 0/1/blur7 α0.5, 하드 다크 2/2/0, 3/3/0] + 모노 그라(흰 → 스킴 베이지). **아웃라인을 이보다 키우면 획이 뭉개진다** — 두께는 헤일로 + 하드섀도 스택으로.

**⚠️ 톤 지시는 은어로 오지 않는다.** "좀 차분했으면"·"은은하게"·"고급스럽게"·"자막이 너무 튄다"(→ 차분), "시원하게"·"눈에 빡 들어오게"·"크게"·"심심하다"(→ 시원). 레이아웃 골격은 두고 **자막·타이포 강도만** 조절한다 — **차분은 가독성을 판(박스)으로, 시원은 헤일로로 확보한다.**

| 축 | 차분 | 시원 |
|---|---|---|
| 자막 `fontSizeRatio`(9:16) | 0.0152 (52px) | 0.021 (72px) |
| 자막 굵기 | Medium | Bold |
| 가독성 | 다크 반투명 판(0.58) + 흰 글씨 | 판 제거 + 흰 헤일로 4겹(blur 12·12·24·40) + 다크 잉크 |
| 키워드 | 단색 | 브랜드 컬러 run 1개 |
| 헤드라인 / 오퍼 배지 | 46~56px / 59px | 82px / 89px |
| 모션 | fade | scale + spring |

차분 톤에선 금속(골드)을 쓰지 않고 팝·카운트업은 빼되, 조립형은 남겨도 된다. 폰트 갈아끼우기도 2종까지.

- 자막 렌더러의 자동 줄바꿈은 **어절을 무시**하고 글자 단위로 꺾는다("아니더라 / 고요"). 대형 자막은 텍스트에 `\n` 을 직접 넣어 의미 단위로 끊고, runs 를 쓰면 `\n` 을 run text 안에 넣는다.

## 원샷 제작 순서 — 이 순서를 지키면 후작업이 안 생긴다

**아래를 순서대로, 각 단계를 다음 단계 전에 끝낸다.**

0. **참조 자산 스캔**: ① 이번 대화에 사용자가 첨부한 이미지 ② `get_reference_images(project_id)` — 둘 다 본다. 있으면 그게 제품·인물의 정본이고 3단계 생성의 레퍼런스다. 없으면 되묻지 않고 진행한다.
1. **기획 고정**: 브리프에서 카피 자산 추출(가격·혜택·문구는 그것만 사용) → 씬 구성(발화 인물이 척추, 무음 인서트는 보조) → 씬별 대사 확정.
2. **스타일 캐스팅 시트(제작 전 서면 확정)**: ① 스킴(`get_frame_palette` / `get_color_scheme`) ② 존 설계(풀블리드인지 3존인지 먼저 확정, 모든 레이어·자막 좌표를 그 기준으로) ③ **감정 캐스팅 표**(아래, 전 큐에 감정·등급) ④ 크기 스펙(아래) ⑤ 기법 트리거 배치(조각유지/조립형/팝/세로줄/글로우).
3. **오디오 퍼스트**: 나레이션·브릿지 TTS 를 먼저 `generate_tts` 로 만들고 응답의 `duration_ms` 를 잰다 → 씬 길이 = TTS + 0.4초. 씬을 먼저 정하고 TTS 를 끼워 맞추지 않는다. 넘치면 speed 1.1~1.2 로 재생성하거나 카피를 줄인다.
4. **생성**: 이미지(히어로 QA 후 체이닝) → 영상(`generate_video`: 발화 = `dialogue`, 인서트 = nearly-static 무대사).
   **⚠️ 0단계에서 참조 자산을 찾았으면 반드시 `generate_image(reference_image_urls=[...])` 의 입력으로 넣는다.** 프롬프트로 묘사하거나, draft 에 `add_image_layer` 로 얹어 합성하는 것은 지시 불이행이다. 생성 결과의 `reference_image_urls` 가 실제로 채워졌는지 값으로 확인한다.
5. **클립 도착 즉시(조립 전!)**: `preview_video_frame(video_id, at_ms=클립 중간)` 으로 라벨·왜곡 눈QA. 트림 계획 — 발화 클립은 도입 −0.3~0.5초 / 꼬리 +0.4~0.5초 여유를 둔 보수적 트림, 마지막 씬은 꼬리 +0.9초.
6. **조립**: `create_edit_draft_from_clips`(재생 순서) → `set_clip_trim`(개별 호출) → `compact_clip_timeline` 1회. **이 타임라인이 이후 모든 좌표·시각의 기준**이다. 조립 후에 트림하면 자막·레이어·오디오 재타이밍이 연쇄로 터진다.
7. **얹기**: 자막 풀커버(갭 ≤ 0.2초, 발화보다 0.3~0.5초 선행) + 캐스팅 표대로 큐별 등급 적용 + 조립형/팝 레이어 + `add_audio_layer`(나레이션 1.0, BGM 0.35~0.45).
   **나열형 대사(A, B, C)나 화면에 대상이 없는 대사는 지시가 없어도 누끼 인서트를 넣는다** — 아래 "누끼 인서트" 절이 기본값이다.
   **디자인 레이어(상단 고정 문구·브랜드 판·고지 바)는 아래 마감 게이트를 따로 통과시킨다.**
8. **QA(전부 통과해야 완료)**: ① 얼굴 가림 — 씬 수만큼 프레임 ② 밀도 — 자막+레이어 커버리지 갭 계산 ③ 25% 축소 가독 ④ 줄바꿈·겹침 ⑤ 캐스팅 검사(전 큐 등급 / L3 1~3개 / 배역 폰트 2종 이하 / 포맷별 크기 환산).

### 감정 캐스팅 — 큐마다 판정하고, 반응은 4등급으로

**모든 큐에 감정을 단다. 단 반응은 등급을 나눈다** — 전 큐를 시끄럽게 만들면 강조가 사라지고 폰트 견본이 된다.

| 등급 | 언제 | 수단 | 예산 |
|---|---|---|---|
| **L0 중립** | 정보·연결 대사 | 마스터 스타일 그대로 | 나머지 전부 |
| **L1 포인트** | 숫자·브랜드·핵심어가 든 대사 | 마스터 + **키워드 run 색만** | 큐의 30~50% |
| **L2 배역** | 감정이 뚜렷한 대사 | **폰트 스왑 + 채움색**(`update_subtitle_entry.style`) | 큐의 10~20% |
| **L3 승격** | 소재의 감정 최고조 | **textFx**(2중 테두리 + 데코) | **소재당 1~3개** |

**캐스팅 표를 먼저 쓴다(세는 산출물).** 조립 전에 전 큐를 한 줄씩:

| 큐 | 대사 | 감정 | 등급 | 배역/수단 |
|---|---|---|---|---|
| c0 | 임플란트가 35만원이라길래 | 정보 | L1 | 마스터 + `35만원` 옐로 |
| c1 | 잇몸 지대주도 크라운도 | 정보 | L1 | 마스터 + 구성어 옐로 |
| c2 | 진짜 저렴하게 해결했어요 | **만족** | **L3** | **금빛 textFx** |

### 감정 → 배역표

레시피 수치(그라데 stop·획 폭·글로우 스택)는 `variety-caption-style` 스킬 "감정 데코 자막 5종".

| 감정 | 대사 신호 | 배역(폰트) | 채움 / 획 | 가능 등급 |
|---|---|---|---|---|
| **만족·득템·성취** | "저렴하게 해결", "이만한 게 없어요" | `PyeongChangPeace-Bold` | 금 그라데 + 갈색·흰 2중 | L2~L3 |
| **분노·흥분** | "열받았어", "어이가 없어서" | `Tenada` | 주황 그라데 + 흰·진빨강 2중 | L2~L3 |
| **공포·불안** | "무서웠어요", "큰일 나는 줄" | `FUNFLOW-SURVIVOR-KR` | 흰 채움 + 붉은 글로우 4단 | L2~L3 |
| **애정·설렘** | "너무 좋아요", "예뻐졌죠?" | `RoomNo703` | 마젠타 + 흰·핑크 2중 | L2~L3 |
| **우울·체념** | "포기했었어요", "속상했죠" | `EF_제주돌담체(OTF)` | 차콜 + 흰 소프트 글로우 | L2~L3 |
| 놀람·발견 | "진짜요?", "그렇대요" | 마스터 유지 | 키워드 run 만 | L1 |
| 정보·설명 | 조건·구성 나열 | 마스터 | — | L0~L1 |

**배정 3원칙**: ① 한 소재에 배역 폰트는 2종까지 ② 같은 감정이 연속되면 첫 큐만 올린다 ③ 애매하면 L0.
**L2 는 2중 테두리를 못 쓴다** — 자막 큐엔 `stroke2` 가 없다. 2중 테두리와 데코가 필요하면 L3 로 올린다.

### ⚠️ 포맷별 크기 환산 — 가로 소재에서 매번 밟는다

렌더px = `fontSizeRatio × H² / 1080` 인데 **H 가 포맷마다 다르다**:

| 포맷 | H | 렌더px |
|---|---|---|
| 9:16 | 1920 | `ratio × 3413` |
| 1:1 | 1080 | `ratio × 1080` |
| **16:9** | **1080** | **`ratio × 1080`** |

**세로 소재에서 쓰던 ratio 를 16:9 에 그대로 넣으면 3.2배 작아진다.** 이 스킬의 px 수치는 대부분 세로(1080×1920) 기준이다.

목표 렌더px → ratio (16:9 / 9:16):
- 자막 본문 84~90px → `0.078~0.083` / `0.025~0.026`
- 승격 캡션 90~100px → `0.083~0.093` / `0.026~0.029`

`add_text_fx_layer` 의 `fontSize` 는 축이 다르다 — 에디터 px 이고 렌더 = `px × H / 1080`. 16:9 면 그대로, 9:16 이면 1.78배.

### 디자인 레이어 마감 게이트

**"자막은 괜찮은데 상단 디자인이 엉망"** 이라는 피드백의 원인은 능력이 아니라 **완료 판정 기준의 부재**다. 자막은 큐가 24개면 24번 하면 끝이 자명한데, 디자인 레이어에는 그 "끝"이 없어서 프리뷰 한 번 안 보고 던지게 된다. 그래서 아래를 쓴다.

**① 소재 유형을 먼저 정한다 — 밀도·모션이 여기서 갈린다**

| | 브랜드 필름형(15초, 씬 전환) | **롱폼 고정헤더형(30~60초, 상세 나레이션)** |
|---|---|---|
| 레이어 | 5~9장, 씬마다 교체 | **3~8장, 전 구간 고정** |
| 타이밍 | 씬 단위 start/end | **0 → 전체 길이** |
| 모션 | 필수 + 90ms 스태거 | **넣지 않는다** |
| 내용 운반 | 디자인 레이어 | **자막이 운반** |

상단 고정 문구는 원래 안 움직이는 게 관습이다. 56초 소재가 디자인 3장으로 그대로 승인된 실측이 있다 — **개수를 채우려고 레이어를 늘리지 않는다.**

**② 마감 6게이트 — 사람이 실제로 고친 것 전부**

| 게이트 | 실패 실측 | 통과 조건 |
|---|---|---|
| 판 내 정렬 | 밴드 445px 안에서 위 213 / 아래 43 | **프레임 종속**으로 만든다. 절대좌표면 상·하 여백 차 ≤ 판 높이의 20% |
| 폰트 크기 하한 | 하단 소카피 19px → 사람이 32px | 헤드라인 44 / 서브 28 / 라벨 24 / 소카피 28 / 주석 12(렌더px @9:16) 미만 금지 |
| 패널 기본값 | `#000 opacity 1` 하드엣지 막대 | **스크림이 기본**: `backgroundGradient` 투명→검정 `angleDeg:180` |
| 블리드 | 브랜드 아트를 캔버스에 딱 맞춤 | 풀블리드는 캔버스 **+8~12%** |
| 아웃라인 | 골드 그라데 위 흰 5px → 번짐 | 검정, fontSize 의 4~6%. **흰 아웃라인 금지** |
| 배경 밝기 | 밝은 배경에 골드 그라데 → 묻힘 | 레시피 전에 `get_frame_palette`. 밝으면 단색 + `textShadows` 글로우 |

**③ 완료 = 프리뷰를 눈으로 본 뒤.** `apply_edit_batch` 의 `failed=0` 은 "들어갔다"이지 "봐줄 만하다"가 아니다. `preview_edit_frame` 최소 1장 → 6게이트 대조 → 수정 → 재프리뷰.

### 렌더 실행 규칙

**렌더는 사용자가 시켰을 때만 돌린다.** `render_edit_draft` 는 "렌더 돌려"·"뽑아줘"·"출력해줘" 같은 명시 지시가 있을 때만. 소재를 다 만들었어도 **프리뷰까지가 완료**다. 완료 보고에서 프리뷰를 보여주고 "렌더 돌릴까요?" 한 줄로 묻는다. 렌더는 비용·시간이 들고, 검수 전 렌더가 쌓이면 어느 게 최종본인지 구분이 안 된다. 예외는 "만들고 렌더까지 해줘"처럼 미리 위임한 그 1건뿐이다.

## 상위 원칙 (반려에서 나온 것)

1. **목소리는 개수가 아니라 역할 구조다.** 한 소재에 TTS 목소리 둘도 괜찮다(질문자 + 답변자처럼). 반려되는 건 **역할 없는 목소리** — 화자와 비슷한 목소리가 아무 정체성 없이 말을 이어받아 동일인처럼 헷갈리는 경우다. 역할을 정의 못 하겠으면 빼라. 목소리도 폰트처럼 **대비**(성별·톤)로 캐스팅한다.
2. **오디오 구성은 기획서·사람 지시가 우선이다.** 지시가 없을 때의 참고 분포: 목소리 1.0 / BGM 베드 풀길이 0.35~0.45 / 포인트 효과음 0.5~0.6. 목소리만 있는 믹스는 갭마다 죽은 공기가 들린다.
3. **밝은 풀블리드 위 밝은 텍스트 금지.** ① 텍스트를 다크 잉크로 반전(다크네이비 #16295C + 흰 소프트 글로우) ② 밝은 색 텍스트는 다크 판·스크림 위에서만. 연한 accent 는 다크 서피스 전용이다.
4. **박스 위 텍스트는 프레임 종속(flexbox)이 정석이다.** 절대좌표 y 손계산으로는 정중앙이 안 나온다. `add_frame_layer`(박스 비주얼 + layout) → 반환된 id 를 `add_text_layer` 의 `parent_id` 로. 자식 텍스트 폭은 실폭 이상(좁으면 2줄로 꺾여 프레임 밖으로 넘친다). 프레임 안폭 = width − padding×2 ≥ 글자수 × 0.88 × fontSize.
5. **레이어 리타이밍은 `patch` "안에" start_ms/end_ms.** `update_text_layer`/`update_shape_layer` 는 patch 객체 내부의 `start_ms`/`end_ms` 를 처리한다. **op 최상위에 두면 조용히 무시된다.** 자막은 `update_subtitle_entry` 로(역순 업데이트로 인덱스를 안정시킨다).

## 실전 보강

- **같은 문구 이중 노출 금지**: 발화 자막과 화면 카피 레이어(조립형·팝)가 같은 문구면 **자막을 지우고 레이어가 자막을 겸한다.**
- **TTS 인서트 오프셋은 씬 시작 고정이 아니라 앞뒤 발화 갭 균형으로.** 발화끝 → 다음 발화시작 갭을 표로 계산해 0.9초 미만으로 맞춘다. 마지막 씬 꼬리 0.9초 여운만 예외.
- **레이어 좌표는 클립 QA 프레임에서 얼굴 위치를 먼저 읽고 잡는다.** 인물이 우측이면 팝을 좌상단에, 얼굴이 상단 중앙이면 조립형을 중하단 스크림 위에. `get_frame_regions` 의 `subject_bbox` 로 값 대조.
- **`apply_edit_batch` 의 `add_layer` 는 text/audio 레이어에도 x/y/width/height 필수**(오디오는 더미 0/0/0.1/0.05). 빠지면 배치 전체가 거부된다.
- **그라데이션 stop 의 알파는 rgba 색이 아니라 `opacity` 필드에** 둔다(`{color:'#060c1e', opacity:0~1}`). rgba 알파는 편집기 왕복에서 사라져 스크림이 불투명 벽이 될 수 있다.
- **Kling `duration_seconds` 는 3/4/6/8/10/12/15 중 하나.** 5를 넘기면 거부된다. dialogue 가 있으면 서버가 대사 길이로 자동 산정한다.
- **dialogue 프롬프트에 한숨·망설임 연기를 시키지 않는다.** "small sigh", "pause" 를 넣으면 그대로 생성돼 늘어짐이 박힌다. 발화 지시는 이 문구를 붙인다: *"delivers the line immediately and continuously — no sighing, no long pauses, no filler sounds — and stops right after finishing the line."* 이미 박힌 한숨은 재생성이 정석이고, 아까우면 같은 영상을 `add_clip` 으로 슬롯 복제해 포즈 앞뒤로 `set_clip_trim` 하는 점프컷으로 도려낸다.

## 누끼 인서트 — 기본값 (지시 없어도 넣는다)

영상 한 컷이 대사를 다 못 보여줄 때, 항목별 누끼(배경 없는 PNG)를 **단어가 나오는 순간에 슉슉 팝인**시켜 화면을 채운다. 2026-09-19 장염 릴스 5번 씬(커피·탄산·술)에서 실측.

**트리거(하나라도 맞으면 넣는다)**
- 대사가 나열형이다: "A, B, C" / "A·B·C도 잠시 멈춤" — 항목 1개당 누끼 1장.
- 대사의 대상이 그 컷에 안 보인다(술 얘기인데 술이 없다).
- **넣지 않는 경우**: 컷이 이미 그 대상을 보여준다(죽·계란·두부 트레이 위에 죽·계란·두부 누끼는 중복). 한 씬에 4장 넘게 쌓지 않는다.

**타이밍(오디오 퍼스트와 같은 원칙)**
1. 나레이션 mp3 의 무음 구간을 잰다 — `run_code` 의 `jig.silence(src)`(또는 ffmpeg `silencedetect=noise=-32dB:d=0.12`). 쉼표·마침표가 무음으로 잡힌다.
2. 항목 단어의 시작 = 그 구절의 발화 구간을 항목 수로 등분한 지점(3항목 0.9초 구절이면 0 / +0.3 / +0.6초). 정밀 STT 는 필요 없다 — 등분 오차 0.1초는 안 보인다.
3. `start_ms` = 단어 시작, `end_ms` = 씬 끝. 먼저 나온 항목은 남아 있고 다음 항목이 옆에 쌓인다.
4. 모션: `set_layer_motion` `{enter:{type:'pop', easing:'spring', durationMs:420}}`. 스태거는 단어 간격(≈300ms)이 대신한다.
5. **마지막 항목 홀드 ≥ 0.9초**. 구절이 씬 끝에 붙어 있어 못 지키면 그 씬 클립을 `set_clip_trim`(out +0.5초) → `compact_clip_timeline` → **뒤 씬의 자막·나레이션·데코·CTA·고지 문구 start/end 를 전부 +Δ** 로 밀고, 그 씬 마지막 자막 큐의 end 도 씬 끝에 맞춘다(커버리지 갭 0). 밀지 않으면 나중 레이어가 앞 씬으로 넘어온다.

**배치(9:16 실측)**
- 폭 0.22~0.30(항목 원본 비율로 height 계산: `h = w × 1080/1920 × (img_h/img_w)`), 세로 중간띠 **y 0.30~0.52** — 자막존 위, 상단 라벨 아래.
- 3항목 x = 0.06 / 0.39 / 0.66, 2항목 x = 0.14 / 0.56. 얼굴이 있으면 얼굴 반대편 반쪽에 세로로 쌓는다.
- 복잡한 배경(음식 테이블·탑뷰)에서 분리감은 하드 그림자로: `update_layer_box` `patch.effects = [{type:'dropShadow', params:{radius:18, x:0, y:14, color:'rgba(0,0,0,0.55)'}}]`. 흰 판·원형 배지는 넣지 않는다(스티커 느낌으로 촌스러워진다).

**소재 — 우선순위대로**
1. 사용자가 올린 누끼(`list_uploads` / `list_layer_images`)가 있으면 그것.
2. **생성 + 키잉(기본)**: `generate_image(aspect_ratio='1:1')` 로 항목 하나만 **단색 초록(#00FF00) 배경**에 뽑고 `run_code` 로 알파를 뚫어 `jig.upload_image(..., project_id=)` → `add_image_layer(url, asset_id)`. 절차와 코드는 [references/cutout-insert.md](references/cutout-insert.md).
   - **흰 배경으로 생성하지 않는다.** 흰 잔·은색 캔이 배경과 같은 값이라 플러드필이 물체 안으로 샌다(실측: 커피잔 윗면이 잘려 나감). 초록 배경은 흰·은색·유리 물체도 깨끗하다.
   - 프롬프트에 "single object, centered, flat solid green background filling the frame, no shadow on the background, no text" 를 넣는다. 스타일이 한 세트로 맞는 것이 이 경로의 장점이다.
3. 무료 검색(`search_images` → `preview_image_candidates` → `import_images_from_urls`)은 **최후 수단** — Pixabay 투명 PNG 는 만화·벡터·사진이 섞여 한 화면에 나란히 놓으면 톤이 깨진다. 쓴다면 셋 다 같은 계열(전부 벡터 또는 전부 사진)만.

**함정**
- 생성 이미지의 `public_url` 은 private 버킷이라 샌드박스에서 400 — `jig.api('/image-gen/{id}/status', method='GET')['public_url']` 의 서명 URL 로 받는다.
- `jig.upload_image` 는 `project_id=` 없이 실패한다. 결과 `url` 은 서명 URL 이라 `add_image_layer` 에는 `?token` 앞까지의 public 형태 URL + `asset_id` 를 넘긴다(인터셉터가 재서명).
- 컵 손잡이 구멍처럼 **테두리와 안 이어진 배경**은 플러드필이 못 지운다 → 채도 높은 초록(gd > 140)은 연결과 무관하게 배경으로 친다.

## 타임라인 밀도 QA — 퍼포먼스 소재는 꽉 차야 한다

- **시각 밀도**: 하단 자막존이 영상만 노출되는 구간 없이 이어져야 한다. 자막 start/end 를 씬 경계에 물려 **커버리지 갭 ≤ 0.2초.** 자막+레이어 인터벌을 합쳐 계산으로 검증한다.
- **오디오 밀도**: 나레이션·발화 구간을 표로 펼쳐 무음 0.9초 이상 구간을 찾는다. 씬 전환 호흡 1곳 정도만 허용한다. 최종 확인은 렌더 결과로.
- 무음 인서트 씬(제품컷)은 브릿지 TTS 로 채운다. TTS 음성에는 꼬리 무음 ~0.3초가 있으니 배치 계산은 실효 발화 길이로.

## 함정

- **렌더 폰트 공식**: 렌더px = ratio × H² / 1080. 원하는 렌더px 에서 ratio = px × 1080 / H². 안 하면 전부 크게 나와 줄바꿈이 무너진다.
- 프리뷰는 (draft, format, at_ms) 로 캐시된다 — 수정 확인은 at_ms 를 바꿔서.
- 사용자가 편집기로 확인할 땐 **어느 포맷 탭인지 먼저 맞춘다.** 포맷마다 자막이 따로라 "적용 안 됐다" 신고의 단골 원인이 포맷 불일치다.
- 스타일이 많이 들어간 소재(다중 그림자·거친 테·run 별 테두리)는 편집기에서 한 번 열어 렌더 결과와 같게 보이는지 확인한다. 다르면 문의한다.
