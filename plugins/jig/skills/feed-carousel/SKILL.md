# 피드 캐러셀 제작

**전제**: `ad-creative-core` §피드(정지형) 소재를 먼저 읽는다 — 도구(`create_feed_draft` / `add_feed_page` / `export_feed_pages`), 4:5 폰트 공식(렌더px = ratio × 1687.5), 도구 필드 함정. 여기는 **무엇을 어떻게 디자인하는가**다.

## 콘텐츠 방향

- **정보성 > 유머.** AI 유머 캐러셀은 "유치하다"로 반려된 실측이 있다(디자인은 승인, 콘텐츠 반려). AI 가 잘하는 건 정확하고 밀도 있는 실용 정보의 큐레이션·압축 — 팁/하우투/치트시트/비교.
- **시리즈로 설계한다.** 단발이 아니라 "컨셉 잡고 계속 뽑는" 구조 — 시리즈명 칩(EP 번호), 고정 팔레트·타이포. 피드 그리드에 나란히 놓였을 때의 통일감이 곧 계정 브랜딩이다.
- **사실 검증**: 팁·수치·단축키·명령은 확실히 아는 것만. 불확실하면 페이지를 빼지 지어내지 않는다.
- **꿀팁 판정 게이트**("뭐 어쩌라는거야" 반려의 답): 일반론("지도 앱 깔아라", "상담 먼저 해라")은 팁이 아니다. 모든 팁 불릿은 ① 모르면 **돈이나 시간을 실제로 잃는가** ② 구체 조건·숫자·행동이 담겼는가 ③ 현지인만 아는 비직관 사실인가 — 셋 중 둘 이상. 못 넘으면 페이지를 갈아치운다.
- 이미지: 생성형 필수 아님. 타이포/컴포넌트 주도 페이지가 기본이고, 사진이 필요하면 ① 생성형 ② 라이선스가 명확한 무료 스톡(Unsplash/Pexels) ③ 사용자가 준 사진. **권리 확인 전 인터넷 임의 이미지 금지.**

## 캐러셀 구조 문법

```
p1   표지     — 스크롤을 멈추게 하는 한 장. 그리드 썸네일이 되는 페이지(아래 표지 규칙).
p2~N 본문     — 페이지당 주장/팁 정확히 1개. 고정 그리드(같은 위치에 같은 요소) + 페이지 번호.
pN+1 마무리   — 캐러셀 CTA 는 SAVE("SAVE THIS")가 팔로우보다 강하다. 팔로우는 서브로.
```

- 본문은 **템플릿 1장 만들고 `add_feed_page(copy_from_idx)` 로 복제 후 내용만 교체** — 통일감의 기계적 보장. 페이지 수 3~10(도구 한도 10).
- 페이지 번호 pill(n / N)은 본문에만. 표지·CTA 엔 시리즈 칩.

## 표지는 목차가 아니라 미끼

"뭐 사야 돼?", "마무리감으로 고르세요" 같은 표지는 비교표 제목이라 넘길 이유가 없다. 잘 되는 계정의 표지는 **풀블리드 클로즈업 + 큰 숫자 + 주장/질문형 헤드라인**이다.

**표지 공식 4종**
1. **왜 질문** — "왜 요즘 틴트는 죄다 젤리가 됐을까"
2. **상황 지목** — "점심만 되면 얼굴 번들거리는 사람만 보세요"
3. **반전 단정** — "마스크가 흘러내리는 건 얼굴 탓이 아니에요"
4. **숫자 재프레임** — "커피값이 1억이 되는 데 걸리는 시간"

제품명·"3개 비교" 표지 금지. 지어낸 주장 금지 — 사실에서 출발한다.

**표지 레이아웃(4:5)**: 풀블리드 클로즈업 사진 → 하단 스크림(y 0.32~, 0.55 → 0.93) → 좌상단 시리즈 키커(20px 자간 4) → 우상단 회차 숫자(210px, 시리즈 디스플레이 폰트) → 하단 앵커: 셋업 한 줄(세리프/미디엄 32px, 흰색 78%) + 헤드라인 2~3줄(84~120px, 줄마다 별도 레이어, 강조 줄 한 줄만 액센트색) → 우하단 "→". ratio 는 정확한 px 공식(px × 1080 / H²)으로.

## 디자인 시스템 A — "Corporate Ink" (컴포넌트형)

사진이 없거나 보조인 콘텐츠(UI 패러디·키캡·타이포 주도)에 쓴다.

**팔레트 토큰**: INK `#0B1630` · NAVY `#14213D` · BLUE `#0A66C2` · BLUE2 `#3B82F6` · PAGE_BG `#F3F6FA` · GRAY `#55606B` · CHIP_BG `#EAF1FB` · 다크 위 라이트텍스트 `#9DBCF3`/`#7C90B8`.
**폰트 배역**: 헤드라인/빅넘버 = Anton(textFx) · 이름/키워드 = Archivo Black · UI/칩/버튼 = Poppins ExtraBold · 본문 = Poppins Bold.

### 레시피 (값 그대로 재사용 가능)

1. **메탈 그라데(실버-블루)** — 금속 공식은 중간 흰 stop:
   `{"angleDeg":180,"stops":[{"color":"#EAF2FF","offset":0},{"color":"#FFFFFF","offset":42},{"color":"#C9DCF7","offset":66},{"color":"#7FA3D6","offset":100}]}`
2. **스티커 팝 헤드라인(textFx, 밝은 배경)**: Anton 100~120, fillGradient = 메탈, strokeColor INK **width 5~6%**, stroke2Color #FFF width +7~8(이중테), shadows [하드 `{ink 0.5, 0, 7, 0}`, 소프트 `{ink 0.38, 0, 18, 30}`]. 멀티라인은 `\n`.
3. **다크 배경 대형 타이포(textFx)**: 이중테 대신 **글로우** — stroke INK 7, shadows [`{rgba(96,160,255,0.55),0,0,42}`, `{rgba(4,10,26,0.85),0,9,0}`].
4. **스크림**: 사진→타이포 존 `rgba(255,255,255,0.92)→0`(밝은 쪽), 사진→다크 존 `rgba(11,22,48,0)→0.92`(angleDeg 180). 사진→대지 페이드는 대지색 0→1.
5. **플로팅 카드**: frame, bg #FFF **backgroundOpacity 1 명시**, radius 30, border #E3E9F4 1.5, `effects:{shadowColor:"rgba(13,30,64,0.18)",shadowBlur:48}`. 사진 하단에 살짝 겹쳐 띄운다.
6. **pill 칩/버튼**(frame + 자식 텍스트 flow — 텍스트 y 손계산 금지): radius 40. 칩 = CHIP_BG + border #CFE0F5 1.5 + BLUE 텍스트. 주 버튼 = 그라데 `[BLUE2→BLUE]` + 흰 텍스트 + 블루 글로우 섀도. 고스트 버튼 = 흰 + BLUE 보더 2.5.
7. **키캡**(단축키 콘텐츠): frame radius 14~16, bg 그라데 `#FBFDFF→#DDE5F2`(180°), border #B9C6DC 2, `effects:{shadowColor:"rgba(13,30,64,0.35)",shadowBlur:10}` + 자식 글리프/라벨 NAVY. 글리프(⌘⇧⌃)는 폰트에 따라 tofu 가 날 수 있다 — 프리뷰 후 안 되면 CMD/SHIFT 텍스트 라벨로.
8. **다크 페이지 배경**: shape 그라데 `#0B1630→#16294D(52%)→#0A1327` + 라디얼 글로우 1겹 `backgroundRadialGradient {cx50, cy50, radius ~58, rgba(96,160,255,0.30)→0}`.
9. **고스트 빅넘버/워터마크**: textFx Anton 대형, fill `rgba(140,175,235,0.14)` — 본문 페이지 위계용 배경 장식.
10. **서클 아바타**: circle 도형(흰, 글로우 섀도) 링 + 이미지 `mask:{kind:circle,size:62,feather:2}`(size 는 반지름% — 99 는 노크롭).

### 크기 스펙 (4:5 = 1080×1350, 렌더px = ratio × 1687.5)

## 디자인 시스템 B — 에디토리얼 (사진이 주인공)

**여행·음식·현장처럼 사진이 주인공인 콘텐츠는 에디토리얼이 정본이다.** 흰 카드/칩/배지로 사진을 가리는 컴포넌트 스타일은 여행 시리즈에서 "바이브코딩한 쓰레기"로 반려됐고, 레퍼런스(IG 여행 캐러셀)와 대조해 재작업으로 통과했다.

- 사진 풀블리드 100% — 카드·판으로 가리지 않는다.
- 하단 스크림: y 0.36~, `rgba(0,0,0,0)→0.70@50→0.96@100`(밝은 사진 기준). 상단 얇은 스크림 `0.55→0` h 0.14(라벨 받침).
- 헤드라인: **Anton 옐로(#FFE843) 플랫 + 섀도** `[{black 0.9,2,3,4},{black 0.55,0,0,22}]` — 이중테 아님. 좌정렬 x 0.06, ratio 0.035~0.052.
- 본문: **불릿 3줄** "• 리드인: 내용" — 리드인은 runs 로 옐로+이탤릭+800, 본문 흰 700. ratio 0.018, lineHeight 1.42. **불릿은 1줄로 설계** — 래핑 고아 단어가 생기면 카피를 줄인다.
- 라벨: 칩 없이 맨 텍스트 — 시리즈명 옐로 자간 6 좌상, "n / N" 흰색 우상.
- 사진 캐스팅: **하단 1/3 이 조용한(어두운/단순한) 컷**이어야 스크림이 먹는다. 커버만 밀도 높은 컷 허용(스크림 진하게).
- 밝은 요소가 섞인 사진 위 소형 텍스트는 스크림 대신 **다크 헤일로 스택** `textShadows [다크 blur10 ×2, blur22, blur38]` — 사진 무드를 보존한다.

**뷰티 변주 "Rose Editorial"**: 문법은 같고 토큰만 교체 — 헤드라인 **Playfair Display Bold 타이틀케이스 + 로즈골드 그라데** `[#FFE4E0@0, #FFF9F6@40, #F5BEC8@70, #D793A8@100]`, 액센트 옐로 → 블러시 `#FFB9C9`, 스크림 블랙 → 딥플럼 `rgba(26,10,18,…)`. **시리즈별 변주 = 헤드라인 서체 + 액센트 + 스크림 틴트 3개만 바꾸고 구조(불릿·라벨·좌표)는 고정.**

## 디자인 시스템 C — 커머스 큐레이션

### "Product Editorial" (매거진 문법)
화이트 카드 + PICK pill 조합은 "허접하다"로 폐기됐다. **카드·캡슐 pill 류 컴포넌트 UI 는 커머스에서도 금지**, 매거진 문법으로 짠다.
- 풀블리드 제품 사진 상단 58%(표지 62%) objectFit cover + 하단 **페이퍼 페이드**(rgba(251,242,239,0)→1 @85, h 0.19) + 페이퍼 존 #FBF2EF.
- **형광펜 마커 셰이프는 반려됐다**("악효과"). 강조는 색(코랄 runs)으로만.
- **구매 이유 블록**("제품 나열만 있고 왜 사야 하는지 없다" 반려의 답): 제품명 아래 ① 브랜드 인용 풀쿼트 한 줄(Playfair 0.0265, 따옴표만 코랄 runs, **1줄 엄수 ≈ 34자 이하**) ② 브랜드 하이라이트 3줄("·  " 코랄 + 본문, lineHeight 1.6) ③ 출처 마이크로("Brand highlights · official product page."). 효능성 문구도 **브랜드 말 인용 + 출처**면 실을 수 있다. %·순위 클레임은 인용이어도 피한다.
- 고스트 빅넘버: 페이퍼 존 우측 "01" Playfair ratio 0.185, rgba(58,26,40,0.06).
- 이미지 크롭: 이미지 레이어는 중앙 크롭뿐이다. 배지·펌프가 잘리면 **창 비율과 같은 비율의 원본**을 쓴다. 표지와 픽 페이지는 **다른 컷**을 쓴다.

### "Fresh Sticker" (산뜻·심플)
레퍼런스 = 매장 릴스 썸네일(사진 위 두꺼운 흰 테두리 스티커 타이포 + 노랑 하이라이트 + 별).
- **토큰**: INK `#14161A` · YELLOW `#FFE04A` · 대지 흰색. 헤드라인/제품명/숫자 = **Lilita One**, 라벨 = Pretendard ExtraBold(자간 2.5~3), 본문 = Pretendard Medium.
- **표지**: 사진 풀블리드 + textFx 3줄 센터 스택 — L1 카테고리(Lilita 104, 노랑 fill, INK stroke 5 + 흰 stroke2 13, 하드섀도 y7 + 소프트 y16/blur28), L2 소문구(58, 흰 fill + INK stroke 5), L3 페이오프(92, INK fill + 흰 stroke 11). 하단 흰 스크림(0→0.92, h 0.16) 위 micro + 검정 SWIPE pill. 별 `★` 3개(회전 ±10~18°) — 글자 위에 걸치면 옮긴다.
- **픽 페이지**: 사진 상단 60% + **흰 시트 radius 44 가 y 0.565 부터 사진 위로 올라온다**(이미지는 라운드 불가 → 시트 쪽을 둥글게, 위쪽 그림자 offsetY −8). 좌상 번호 스티커 textFx "01". 시트 안: 브랜드 캡스 / "01 / 03" → 제품명 Lilita ratio 0.0415(≈ 29자까지 1줄) → **노랑 판정 칩**(frame auto_width, padding 10, radius 8) → 이유 2줄 → `✓ Get it if: …` 한 줄.
- **카피 3단(판정 → 이유 → 대상)** — "이게 뭔데, 이걸 사라고?" 반려의 답: ① 노랑 칩 = **계정의 한 줄 판정**(≤ 34자, 브랜드 인용 아님) ② `WHY IT'S HERE` 라벨 + 본문 2줄(≤ 115자 — 이게 뭔지 + 왜 이 리스트에 있는지, 효능 단정은 "the brand says" 로 귀속) ③ `✓ Get it if: …` 한 줄(누가 사면 되는지, 상황 하나).
- **글리프 실측**: `★` `✓` `→` `·` 는 Lilita/Pretendard 정상, **`✦` `✧` `✔` 는 tofu.**

### "UGC Sticker" / "Campaign Key Visual"
- **UGC Sticker**: 사진 풀블리드 + 상단 **기울인 컬러 타일**(frame rotation −7~−8, radius 22~30, 자식 Jalnan2 흰색) + 하단 **Jalnan2 아웃라인 캡션**(textFx 흰 fill + INK stroke 6~9 + 하드섀도 y 6~9, 마지막 줄만 민트). Jalnan2 는 라틴 글리프도 정상.
- **Campaign KV**: 스튜디오 사진 풀블리드 + 좌상 Montserrat 자간 4 kicker + **DM Serif Display 캡스 헤드라인** + 제품명 + **흰 알약 콜아웃 3개**(frame auto_width radius 40 + 섀도). 본문 단락은 없앤다 — 팩트는 알약으로만.
- **제품 컷 → 키비주얼은 `edit_image`**(원본 컷 + "keep label identical, only change scene…")로 만든다. **단품 편집은 라벨을 보존**하지만, `generate_image` 에 제품 3개를 참조로 넣은 트리오 컷은 **라벨을 재창작**한다 → 트리오 컷 금지.

## 채널·산출물 유형

- 계정 소재 착수 시 **`list_channels` 를 먼저** 부른다. 채널 `profile`(persona/voice/language/audience/cadence)이 브리프의 고정 부분이라 되묻지 않는다.
- draft 에는 **`content_type` 을 반드시 단다**: 캐러셀 `ig_carousel`, 단일 `ig_post`, 스토리 `ig_story`, 릴스 `ig_reel`, 유튜브 썸네일 `yt_thumbnail`(피드 draft 16:9), 쇼츠 `yt_short`. 빠뜨렸으면 `set_draft_content_type`.
- 비율·세이프존은 `get_content_type_specs` 가 정본 — 릴스 상단 250 / 하단 340px, 쇼츠 하단 ~400px, 피드는 3:4 그리드 크롭.
- 새 시리즈는 `create_project(channel_id=…)` 로 채널 아래에 만든다.
- **캡션은 `update_draft_meta(draft_id, caption=…)` 로 draft 에 저장**한다 — 사용자는 jig.ai.kr 에서 "캡션 복사"로 붙여넣는다. 제목(title)도 같이 넣으면 카드 제목이 된다.
- 다음 화는 `duplicate_draft` 로 지난 화를 복제한 뒤 사진·카피만 교체한다 — 레이아웃 재조립 금지. 이미 있는 화인지 `list_channel_drafts` 로 먼저 본다.
- **새 화/새 시리즈 디자인**은 복사가 아니라 합성 — `design-corpus` 스킬(배치 스켈레톤 + 슬롯별 원자 + treatment). 새 장치를 만들었으면 레이어 이름을 붙이고 `save_design_asset` 으로 저장한다.
- 인스타 게시(`publish_feed_to_instagram`)는 사용자가 명시적으로 시켰을 때만.

## 워크플로

1. **기획 고정**: 시리즈 컨셉 + 이번 화 주제 + 표지 공식 + 페이지별 내용(팁 1개/장) 서면 확정. 사실 검증.
2. `create_feed_draft`(4:5, page_count = 총 페이지) → 표지 → 본문 템플릿 1장 → `copy_from_idx` 복제 → 내용 교체 → CTA.
3. 조립 규칙: 박스 위 텍스트는 frame 자식으로만(pill 류), 본문 좌측정렬 스택은 절대배치 허용. 불투명 도형은 backgroundOpacity 1 명시. textFx 는 `fx` 필드.
4. **QA**: 전 페이지 `preview_edit_frame`(at_ms 를 바꿔 캐시 회피) → 마감 6게이트(ad-creative-core) + ① 페이지 간 그리드 정렬 일치 ② 25% 축소(그리드 뷰) 가독 ③ 글리프 tofu ④ 카피-사진 정합.
5. 캡션 저장(`update_draft_meta`) → 완료 보고 = 프리뷰 첨부. **`export_feed_pages` 는 사용자 승인 후.**

## 사진 QA — 실측으로 쌓인 반려 사유

- **날짜·세일 배너가 박힌 제품 컷 금지** — 즉시 낡는 거짓 정보다. "증정·Bonus·Gift" 워딩 배지도 반려. 기능 라벨·수상 배지처럼 날짜가 지나도 거짓이 되지 않는 표기는 허용.
- **셀럽·모델 얼굴 컷 금지**(초상권), **캐릭터 IP 콜라보 컷 제외**(권리 한 겹 추가).
- **스톡 사진의 로고·워터마크 확대 검사** — 유니폼 자수, 기기 각인, "MOCKUP" 워터마크가 연속 적발됐다. 작게 보면 안 보인다.
- **다른 나라 사진 섞임 주의** — 한국 콘텐츠에 다른 나라 간판·도시 사진이 섞이면 저격 포인트다.
- **작은 정사각 썸네일로 판정하지 않는다** — 가장자리 배지가 잘려 깨끗해 보이는 착시가 있다. 실제 쓸 비율·크기로 다시 본다.
- **카피-사진 정합**: 용량·성분·향 이름은 **사진에 보이는 값**으로 쓴다(상품명 숫자와 라벨이 다른 경우가 있다). 어긋나면 숫자를 뺀다.
- **클린컷 수가 픽 수를 정한다** — 5픽을 고집하지 말고 3~4픽으로 줄인다(번호·배지 재번호 잊지 말 것). 간판 제품에 클린컷이 없으면 라인업을 바꾼다.
- 같은 제품이 여러 화에 나오면 **다른 컷**을 쓴다(표지·픽 구분 없이).
- 가격은 박지 않는다(변동). 우리가 단정하는 효능 ✗, 사용후기 코스프레("we tried") ✗. 의료 관련 편은 "General info, not medical advice" 한 줄을 표지·CTA·캡션에 넣는다.

## 캡션·해시태그

**캡션 틀**(이 순서로만):
```
[훅 한 줄]  숫자 + 궁금증. 피드에서 이 줄만 보인다(40자 안쪽).
(빈 줄)
[기준 한 문장]  왜 이 묶음인지 — 선정 근거·맥락.
(빈 줄)
01 · 브랜드 제품명 — "브랜드 인용 한 줄." 보조 사실 1~2개
02 · … / 03 · …
(빈 줄)
[정리 한 줄]  독자가 고르는 기준 ("A는 급할 때, B는 플럼핑, C는 진정용").
(빈 줄)
Save … 💾  +  질문 한 줄 👇     ← 저장·댓글 유도(캐러셀 도달의 핵심)
(빈 줄)
해시태그 8~15개
```

**해시태그 규칙**: ① 8~15개(30개는 스팸 신호) ② 계정 고정 태그 2~3개 + 나머지는 주제별 교체 — **매 포스트 같은 블록 복붙 금지** ③ 대형 2~3 + 중형 4~5 + 소형/브랜드 2~4 로 크기 섞기 ④ **브랜드 태그는 그 화에 실제 등장한 브랜드만**(미등장 태그 = 스팸/사칭) ⑤ 타깃 언어에 맞춘다.

**납품 형태**: 사람이 수동 업로드한다면 **포스트 1개 = 폴더 1개**(01.png…, caption.txt). caption.txt 에는 **붙여넣을 본문만** 담는다 — 설명·규칙을 섞으면 헷갈린다.

## 캐러셀 → 릴스

팔로워가 적은 계정은 정지형 캐러셀 노출이 거의 없다. **비팔로워 도달은 릴스에 열려 있다** — 발행한 캐러셀은 릴스로 한 번 더 돈다.

- 피드 draft 는 정지 렌더만 된다. 릴스는 **영상 draft** 로 새로 만든다: 영상 클립이 필요하므로 `generate_video` 로 무대사 정적 배경 클립을 만들거나 기존 클립을 쓰고, `create_edit_draft_from_clips` → 대지 shape(z 0, 전 구간)로 덮은 뒤 페이지 내용을 **시간 구간별 레이어**로 얹는다. 마지막 클립은 `set_clip_trim` 으로 총길이를 맞춘다.
- **릴스 문법**: 풀블리드 · 컷 · **문장이 한 줄씩 등장**(start_ms 스태거 + `motion.enter` slideUp/fade 360ms easeOut) · 컷당 1~1.5초 · 첫 2초 훅. "블러 배경 위 카드 + 슬라이드 전환 + 균일 2초"는 릴스 문법이 아니라고 반려됐다.
- **줌인·스케일 연속 애니메이션 금지** — 브라우저에서 "지진난다"고 반려됐다. 움직임은 등장 모션과 컷에서만.
- 나레이션이 있으면 **VO 가 컷을 끈다**: TTS 를 먼저 만들고 씬 길이 = VO + 400ms 로 역산.
- **9:16 폰트**: 텍스트 `fontSizeRatio = 렌더px / 3413`, textFx `fontSize = 렌더px / 1.777`.
- 세이프존: 안전영역 y 0.10~0.83. 하단 캡션·우측 버튼이 카피를 먹는다.
- 릴스 캡션은 캐러셀보다 짧게(리스트는 한 줄로 압축).

## 이슈 쇼츠 (내레이션형 9:16)

한국 유튜브 쇼츠의 사건·정보 전달 문법.
- **포맷**: 검은 9:16, 상단 고정 제목 2줄(흰 + 노랑, 굵은 한글 외곽선), 가운데 1080×1080 이미지(비트마다 교체, fade 220ms), 하단 외곽선 자막이 문장 단위로 색 순환(흰·노랑·핑크·빨강).
- **만드는 순서**: 대본을 10~11비트로 나눈다 → 비트마다 `generate_tts`(응답 duration_ms 가 곧 비트 길이) → 비트마다 `generate_image`(1:1) → 배경 영상 클립으로 `create_edit_draft_from_clips` → 총길이 `set_clip_trim` → 레이어(검은 대지·제목 textFx·비트별 이미지/자막 textFx/`add_audio_layer`).
- textFx fontSize 는 1080 기준 단위다: 실제 px = fontSize × H / 1080 → 9:16 에서 `fontSize = px × 1080 / 1920`. 자막 62px · 제목 92/104px.
- **대본 규칙**: **실존 인물 사건을 지어내지 않는다**(명예훼손 위험). 정보 테마를 이야기체로 — 첫 문장 = 상황 제시, 둘째 = 반전/숫자, 마지막 = 면책(수익률·의학) + 한 줄 여운. 문장당 3.5~6.5초, 10~11비트 ≈ 45~60초.
- 목소리는 `list_tts_voices` 에서 고른다. 밋밋한 기본 목소리보다 내레이터 톤이 분명한 목소리가 쇼츠 호흡에 맞는다. 나레이션 언어와 보이스 로케일을 맞춘다.

## 함정 (실측)

- textFx 스펙 필드는 **`fx`** — 딴 이름은 조용히 벗겨져 기본 "Text" 로 렌더된다.
- shape/frame **backgroundOpacity 기본값 ≠ 1** — 안 주면 흰 대지와 섞여 물빠진 색이 된다.
- 레이어 x/y/w/h ∈ [0,1] — 음수 블리드 불가. 풀블리드는 objectFit cover 로.
- 이미지 생성은 4:5 미지원 → 3:4 로 뽑고 cover 크롭. 인물 시리즈는 히어로 1장 뽑고 `reference_image_urls` 체이닝.
- 렌더 글리프는 폰트마다 다르다 — 특수문자를 쓰면 프리뷰로 확인한다.
- **반투명 색은 rgba 로 주지 않는다** — `backgroundOpacity` 가 rgba 알파를 덮어써 솔리드가 된다. 반투명 = 솔리드 hex + `backgroundOpacity`(단 그라데이션 stops 안 rgba 는 정상).
- **z 자동 부여를 믿지 않는다** — 스크림이 사진보다 낮은 z 를 받아 아예 안 그려진 실측이 있다. z 를 명시한다: 사진 1 · dim 2 · 스크림 3~4 · 텍스트 10+.
- **`apply_edit_batch` 의 `add_layer` 는 `z_index` 를 무시한다.** 조립 후 `update_shape_layer{patch:{zIndex}}` 로 정정하거나, 순서가 중요한 레이어는 개별 도구(`add_image_layer` 등)로 z 를 지정해 붙인다.
- **`fontSizeRatio` 는 높이 기준이다.** 4:5(H 1350)에서 에디터px = ratio × 1350. 1080 으로 나누면 전부 25% 커진다. 더 안전하게는 batch 로 얹은 뒤 `update_text_layer{patch:{fontSize: px}}`.
- batch 의 `text_props` 에는 `letterSpacing`·`runs` 가 없다 — 자간 라벨은 `add_text_layer` 개별 호출, runs 는 조립 후 `update_text_layer{patch:{runs}}`.
- `text_overflow` 경고는 `\n` 이 든 텍스트를 한 줄로 재서 과대평가한다 — 프리뷰로 최종 판단.
- 이미지 레이어 url 은 patch 로 못 바꾼다 — 교체는 `delete_layer` 후 재-add.
- 제품명이 2줄로 래핑되면 아래 인용구와 겹친다 — 제품명은 1줄로 줄인다.
- **레이어 이름을 고정하면 캡션 자동화가 된다** — 표지 `hl*`·`sub`, 픽 `brand`/`pname`/`quote` 처럼 이름을 붙여두면 `get_edit_draft` 로 텍스트를 읽어 캡션 틀에 주입할 수 있다.
- 한국어판은 번역이 아니라 **재작성**이다 — 한국 IG 계정 어투(해요체·짧은 명사형), 영어 구조 직역 금지, 숫자는 원화 감각으로.
