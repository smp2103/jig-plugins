# 훅과 성과 구조 — "예쁜 광고"와 "먹히는 광고"는 다른 물건이다

이 문서는 **전환을 목표로 하는 소재**에만 적용한다. 브랜드 필름·전시용 소재는
`ad-brand` 스킬 의 미학 규율을 따르고 여기는 무시한다. **둘을 섞으면 둘 다 실패한다.**

시작할 때 **어느 쪽인지 먼저 선언한다.**

| | 성과 소재 (이 문서) | 브랜드 소재 |
|---|---|---|
| 목표 | 클릭·구매 | 인지·태도 |
| 3초 | 패턴 인터럽트 필수 | 분위기로 시작해도 됨 |
| 프로덕션 | 거칠어도 된다(오히려 유리) | 정교할수록 좋다 |
| 카피 | 구체적 이득·숫자 | 톤·서사 |
| 판정 | 훅률·CTR | 상기도·호감 |

---

## 1. 숫자 — 지어내지 말고 이것만 쓴다

교차 확인된 벤치마크(2026-08 조사). 출처는 문서 끝에.

| 항목 | 값 |
|---|---|
| 첫 3초 비중 | Meta 캠페인 가치의 **47%** / TikTok 사용자 **71%**가 3초 내 스크롤 결정 |
| 훅률 하한 | Meta **30%**, TikTok **40%** — 미달이면 예산 대부분이 본론에 도달 못 함 |
| 3초 잔존 | **55%↑** 강한 훅 / **40%↓** 는 수정이 아니라 **재설계** |
| 길이 | **15~25초**. 15초 미만은 맥락 부족, 25초 넘으면 잔존 급락(20~30%) |
| CTA 시점 | 클릭이 **15~20초 구간**에 몰린다 → **전체의 75~80% 지점**. 마지막 프레임은 늦다 |
| UGC vs 폴리시드 | 전환 **3~6% vs 1~3%**, 참여 **2~4배**, CPC 더 낮음 |
| CTR 상위 20% | 이커머스 0.85% / 뷰티 0.72% / 게임 0.68% / 금융 0.48% |

**이 표 밖의 숫자를 소재에 쓰지 않는다.** 가격·할인율·효능·순위는 사용자가 준 것만 쓴다.

---

## 2. 3초 훅 — 여기서 지면 나머지는 존재하지 않는다

### 2-1. 훅은 세 겹이 동시에 걸려야 한다

한 겹만 있으면 훅이 아니다.

1. **시각적 패턴 인터럽트** — 예상 밖의 움직임/구도/색. 첫 프레임이 "잘 찍힌 정물"이면 실패다.
2. **텍스트 훅** — 0.0초부터 화면에 있어야 한다. 페이드인 400ms조차 3초 예산의 13%다.
3. **한 문장** — 두 줄을 동시에 읽히려 하면 둘 다 안 읽힌다.

### 2-2. 훅 유형 (버티컬별로 먹히는 게 다르다)

| 버티컬 | 검증된 훅 형태 |
|---|---|
| 뷰티 | **결과를 먼저, before는 나중에.** 첫 2초 안에 after |
| 이커머스 | **5초 안에 가격 앵커.** 언박싱이면 3초 안에 제품이 보여야 함 |
| 테크/서비스 | **문제 제기** ("아직도 ~하세요?"). 상위 소재 평균 25~35초 |
| 금융 | **교육형 훅.** 크리에이터 계정 형식이 브랜드 계정 형식보다 40%↑ |
| 식음료 | **첫 입 리액션.** 폰 화질이 시네마 화질보다 성과 좋음 |

### 2-3. 훅 문장을 쓰는 규칙

- **주어를 "나"로.** "이 제품은 ~합니다" ✗ / "나 이거 때문에 ~함" ○
- **첫 단어에 정보를 넣는다.** "사실은", "그래서" 같은 접속으로 시작하면 첫 단어를 버리는 것
- **구체 > 형용사.** "엄청 오래가요" ✗ / "12시간" ○
- **완성된 문장을 피한다.** 끝나면 스크롤한다. 열어두면 다음을 본다
- **금지**: 인사("안녕하세요"), 브랜드 소개로 시작, 로고 먼저, 3초 안에 안 나오는 제품

### 2-4. 훅 검증 — 만들고 나서 반드시 한다

`preview_edit_frame` 으로 **at_ms=0, 500, 1500, 2900** 네 장을 찍고:

- [ ] 0ms 프레임에 **텍스트가 이미 있는가** (모션 딜레이로 비어 있으면 실패)
- [ ] 2900ms까지 **제품 또는 사람이 화면에 나왔는가**
- [ ] 첫 문장이 **한 호흡에 읽히는가** (25자 이내)
- [ ] 25% 축소했을 때도 훅 문장이 읽히는가

## 3. 타임라인 — 어디에 뭘 놓는가

15~25초 기준 배분. 총 길이가 다르면 비율로 환산한다.

```
0 ─── 3초      훅          패턴 인터럽트 + 한 문장. 브랜드 언급 금지
3 ─── 8초      맥락        무엇인지/누구를 위한 것인지. 한 컷 한 메시지
8 ─── 15초     증거        사용 장면·비교·수치. 여기가 설득 구간
15 ── 20초     CTA         ★ 클릭이 몰리는 구간. 마지막이 아니다
20 ── 25초     여운        브랜드·반복 CTA. 없어도 되는 구간
```

- **CTA를 마지막 프레임에만 두면 늦다.** 75~80% 지점에 한 번 넣고, 끝에 반복한다.
- **컷당 메시지는 하나.** 한 컷에 헤드라인 2줄 + 서브 1줄이면 셋 다 안 읽힌다.
- **15초 미만 소재**는 증거 구간을 버리고 훅→맥락→CTA 로 압축한다. 다만 전환율은 불리하다.

## 4. 성과 소재의 프로덕션 규율 — 잘 만들수록 불리한 지점

이게 브랜드 소재와 가장 크게 갈리는 부분이다.

- **거친 편이 낫다.** UGC 형식이 폴리시드 대비 전환 2~3배. 손각대·자연광·생활 배경이 신뢰를 만든다.
- **자막은 선택이 아니다.** 무음 재생이 기본이다. 대사가 있으면 100% 자막.
- **첫 프레임에 로고를 넣지 않는다.** 광고임을 3초 안에 인식시키면 훅률이 떨어진다.
- **컷을 짧게.** 정적 구간이 2초 넘어가면 스크롤된다. 켄번스로라도 움직인다.
- **세로 풀블리드.** 레터박스·필러는 그 자체로 "광고"라는 신호다.

**단, 카테고리가 프리미엄이면(가구·주얼리·호텔) 폴리시드가 맞다.** 이때는 성과가 아니라
브랜딩이 목표임을 인정하고 그렇게 판정한다 — CTR로 채점하면 안 된다.

---

## 5. 이 문서가 **다루지 않는 것**

정직하게 경계를 둔다. 여기 없는 걸 지어내면 스킬 전체의 신뢰가 깨진다.

- **"먹히는 문장" 라이브러리가 없다.** 위 규칙은 구조이지 카피가 아니다.
  실제로 성과가 난 레퍼런스를 사용자가 주면 그때 패턴을 추출해 이 문서에 추가한다.
- **한국 시장 데이터가 아니다.** 위 수치는 US/UK/DE/JP/BR 기준이다. 국내 릴스·쇼츠의
  훅률·CTR은 다를 수 있다.
- **A/B 결과가 아니다.** 업계 벤치마크 종합이지 우리 소재의 실측이 아니다.
  집행 데이터가 쌓이면 그걸로 이 문서를 갱신한다.
