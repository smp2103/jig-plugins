# 성과 광고 — 예쁜 것보다 멈추게 하는 것

**전제**: `ad-creative-core` 를 먼저 읽는다. 도구 사용법·좌표/폰트 공식·QA 절차는 거기 있다.
여기서는 **무엇을 만들지**만 다룬다.

**이 스킬의 규율은 미학보다 우선한다.** 정갈함과 성과가 충돌하면 성과를 택한다.
정갈함이 목표라면 이 스킬이 아니라 `ad-brand` 를 써야 한다.

## 판정 기준

훅률(Meta 30%↑ / TikTok 40%↑), 3초 잔존 55%↑, CTR. **완성도로 채점하지 않는다.**

## 워크플로

1. `ad-creative-core` 워크플로를 따르되, 아래를 **먼저** 고정한다:
2. **훅 문장을 제일 먼저 쓴다.** 레이아웃보다 먼저다. 훅이 약하면 나머지는 존재하지 않는다.
3. **타임라인 배분** (총 길이 기준 비율):
   ```
   0~20%    훅       패턴 인터럽트 + 한 문장. 브랜드 언급 금지
   20~50%   맥락     무엇인지/누구를 위한 것인지
   50~75%   증거     사용 장면·비교·구체 사실
   75~80%   CTA ★   클릭이 몰리는 구간. 마지막 프레임이 아니다
   80~100%  여운     반복 CTA
   ```
4. 배치 → 클립 그레이딩 → **훅 검증(§아래)** → 렌더

## 절대 지키는 것 5가지

1. **0ms 프레임에 훅 텍스트가 이미 있어야 한다.** enter 모션 딜레이 400ms 조차 3초 예산의 13%다.
   훅 레이어는 **모션을 걸지 않거나** 120ms 이내로 끝낸다.
2. **컷당 읽는 문장은 하나.** 요소는 20~30개 쌓되(코어 §밀도), **읽히는 건 헤드라인 하나**다.
3. **CTA 는 75~80% 지점에.** 마지막에 한 번 더 반복하는 건 좋지만, 거기만 있으면 늦다.
4. **자막 필수.** 무음 재생이 기본이다.
5. **첫 프레임에 로고를 넣지 않는다.** 3초 안에 "광고"로 인식되면 훅률이 떨어진다.

## 훅 검증 — 만들고 반드시 한다

`preview_edit_frame` 으로 **at_ms = 0, 500, 1500, 2900** 네 장:

- [ ] **0ms 에 텍스트가 이미 있는가** (비어 있으면 실패 — 모션 딜레이 확인)
- [ ] 2900ms 까지 **제품 또는 사람이 화면에 나왔는가**
- [ ] 첫 문장이 한 호흡에 읽히는가 (라틴 25자 / 한글 15자 이내)
- [ ] 25% 축소에서도 훅 문장이 읽히는가

## 성과 소재의 프로덕션 규율 — 잘 만들수록 불리한 지점

- **거친 편이 낫다.** UGC 형식이 폴리시드 대비 전환 2~3배. 손각대·자연광·생활 배경.
- **컷을 짧게.** 정적 구간이 2초 넘으면 스크롤된다. 켄번스로라도 움직인다.
- **세로 풀블리드.** 레터박스·필러는 그 자체로 "광고" 신호다.
- **프리미엄 카테고리(가구·주얼리·호텔)는 예외** — 폴리시드가 맞다. 다만 그때는 성과가 아니라
  브랜딩이 목표임을 인정하고 CTR 로 채점하지 않는다.

## 밀도 — 요소 20~30, 읽는 건 하나

코어 §밀도를 따르되 성과 소재는 **훑기 좋은 장식**을 선호한다:

- 하이라이트 바(형광펜), 카운트업 숫자, 체크 리스트, 화살표, 이모지 스티커
- 진행 표시(1/3, 2/3), 가격 앵커 배지, before/after 라벨
- **금지**: 읽어야 이해되는 장식(긴 각주, 설명 캡션 2줄 이상)
