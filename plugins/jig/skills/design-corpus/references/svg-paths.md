# 손그림 SVG 패스 라이브러리 (shapeKind='svg' + svgPathData, viewBox `0 0 100 100`)

`add_shape_layer` / batch `add_layer(layer_type=shape)` 에 `shape.shapeKind:'svg'`, `shape.svgPathData:<d>`, `shape.svgViewBox:'0 0 100 100'`.
fill = `backgroundColor` + `backgroundOpacity`(1 명시). **렌더러는 path 를 fill 로만 그린다(stroke 없음, evenodd)** — 선처럼 보이는 장치는
링/띠 모양의 닫힌 패스(서브패스 2개)로 만든다. 그라데이션(`backgroundGradient`/`backgroundRadialGradient`)과 `effects` 그림자는 svg 에도 먹는다.
**박스가 정사각이 아니면 반드시 `svgPreserveAspectRatio: 'none'`** — 기본 `meet` 는 100×100 viewBox 를 박스 높이에 맞춰 축소해서
밑줄·점선·테이프·찢김이 점 하나로 사라진다(2026-09-06 실측). 링·스탬프·체크·별처럼 1:1 인 것만 기본값으로 둔다.
회전은 레이어 `rotation`. 색은 팔레트 잉크/액센트. 같은 패스를 두 번 겹치고(하나는 얇게·살짝 어긋나게) 쓰면 "손으로 두 번 그은" 느낌이 난다.

## 쓰는 법 (원자 레시피)

- **손그림 화살표 주석**: `arrow_curved` ink, rotation 으로 조준 + Caveat Bold 메모 + 메모 아래 `marker_stroke` 옐로 opacity 0.9.
- **동그라미 강조**: `scribble_ring` borderWidth 5 accent, 같은 패스 borderWidth 2.5 를 x+2%, y+1% 어긋나게 한 번 더. 가운데 텍스트는 textFx(잉크 획 2 + 그림자 1).
- **테이프**: `tape_strip` #F3E4A6 backgroundOpacity 0.82, rotation -8 + `blend_mode: multiply` 로 아래 사진이 비치게.
- **찢은 종이 판**: rect 판(#FBF8F3) + 아래에 `torn_edge_bottom` 같은 색, 판에 shadow(offsetY 6 blur 18).
- **가격 버스트**: `burst_12` #FFE04A borderColor ink borderWidth 3 + textFx 가격(잉크 획 3, 하드섀도 1) rotation -8.
- **도장**: `stamp_ring_rough` accent borderWidth 5 backgroundOpacity 0 + 안쪽 textFx 트랙드 캡스 roughen{scale 2, freq 0.08} + 전체 rotation -12 + opacity 0.9.
- **말풍선**: rect radius 28 + `speech_tail` 같은 색 + 안쪽 textFx.
