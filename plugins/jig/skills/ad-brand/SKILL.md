# 브랜드 소재 — 완성도로 승부하는 쪽

**전제**: `ad-creative-core` 를 먼저 읽는다. 도구 사용법·좌표/폰트 공식·QA 절차는 거기 있다.

**판정 기준**: 완성도·톤 일관성. **CTR 로 채점하지 않는다.**
클릭이 목표라면 이 스킬이 아니라 `ad-performance` 가 맞다.

## 워크플로

1. `ad-creative-core` 워크플로를 따르되, 아래를 **먼저** 고정한다:
2. **레시피 선언 (제일 먼저)**: `references/genre-recipes.md` §2-3 의 6종에서 **하나를 골라
   스펙 맨 위에 적는다. 금지 목록을 같이 옮겨 적을 것** — 안 그러면 익숙한 장치(칩·언더라인·HUD)로 돌아간다.
   - **직전 2개 소재와 같은 레시피 금지.** `get_recent_layouts` 로 `avoid_devices` 를 먼저 확인한다.
3. **골격 샘플링**: 레시피가 허용하는 범위 안에서 §1 분포로 고른다
4. **자리·색 확정** → 배치 → 클립 그레이딩 → QA

## 이 스킬의 핵심 — 레시피가 모든 것을 이긴다

같은 도구로 10개를 만들면 10개가 똑같아진다. 원인은 취향이 아니라 **기본값으로의 회귀**다.
칩 → 대형 헤드라인 → 언더라인 → HUD 브래킷이 항상 "작동"하기 때문에 매번 그리로 돌아간다.

그래서 레시피마다 **쓸 장치와 금지 장치를 같이 못박는다. 금지 목록이 본체다.**

- 소재 시작 시 레시피를 **먼저 선언**하고 중간에 섞지 않는다
- **밀도(코어 §밀도, 20~30)보다 레시피가 우선한다** — 「미니멀 럭셔리」에 30개를 넣으면 촌스러워진다
- 액센트는 **정확히 1개 요소**에만. 채도 높은 색 2개가 같은 위계로 경쟁하면 반려

## 팔레트 규율

1. `get_frame_palette` 로 화면 실제 색을 읽고 → 응답의 `scheme` 8토큰 확정
2. **소재 전체에서 그 8개만** 쓴다. 여기 없는 색을 새로 만들면 그 순간 톤이 깨진다
3. **존에 따라 다르게**: 그래픽 존(카드·밴드)은 컬러 서피스, **살아있는 영상 위**의 텍스트는 무채 스크림
4. **면적 예산**: bg 45~70% / surface 15~30% / surfaceAlt 8~20% / **accent 3~10%**
5. 본문 회색으로 `#888` 류 순회색 금지 — `textSecondary` 는 base hue 가 섞인 저채도색이다

## 브랜드 소재 QA (코어 체크리스트에 추가)

- [ ] 레시피의 **금지 장치**가 하나도 안 들어갔는가
- [ ] 직전 2개 소재와 골격이 다른가 (`get_recent_layouts` 대조)
- [ ] 액센트가 1개 요소인가, 화면의 10% 이하인가
- [ ] 8토큰 밖의 색이 섞이지 않았는가
- [ ] 25% 축소 썸네일에서도 위계가 읽히는가
