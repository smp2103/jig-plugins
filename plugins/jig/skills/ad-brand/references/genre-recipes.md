## 2. 팔레트 공식

- 패널 색 1·2위: **검정(799회)·흰색(674회)** — 컬러 패널이 아니라 **무채 패널 + 포인트 1색**이 실전 주류
- 포인트 실전 빈도: 브랜드블루 #1677ff, 옐로 rgb(255,235,137)/rgb(253,255,125), 레드 rgb(207,41,41), 오렌지, 딥퍼플 3종(19,3,55/54,3,87/69,9,148), 시안 rgb(0,191,209)
- **반투명 검정 rgba(0,0,0,0.5~0.55)** — 뉴스바/뱃지 pill 용 유의미한 소수파
- 조합 규칙: 검정 패널→옐로/화이트 텍스트, 흰 패널→레드/다크 텍스트, 포인트는 헤드라인 키워드·언더라인·CTA 밴드에만

### 면적 배분 — 색 선택보다 중요하다 (2026-07-30 이식)

| 역할 | 가시 면적 | 하는 일 |
|---|---:|---|
| bg | 45~70% | 분위기와 여백을 만든다 |
| surface | 15~30% | 헤드라인·정보가 앉는 면 |
| surfaceAlt | 8~20% | 구역 분리, 블롭/밴드/카드 |
| **accent** | **3~10%** | 오퍼·뱃지·CTA — 면적이 작을수록 강해진다 |
| textPrimary/Secondary | 필요한 만큼 | 읽히는 게 유일한 목표 |

**같은 색이라도 면적이 틀리면 아마추어처럼 보인다.** accent가 10%를 넘으면 포인트가 아니라 배경이 되고, 채도 높은 색 2개가 같은 면적이면 위계가 사라진다. `get_color_scheme` 응답의 `area_budget`이 이 값을 그대로 준다.

### 디렉션 레시피 8종 — `get_color_scheme(preset)`

| preset | 무드 | 언제 |
|---|---|---|
| `cheerful_sale` | 웜크림 + 비비드레드 + 골든옐로 | 쿠폰, 1+1, 시즌 리테일, 식품 행사 |
| `fresh_seasonal` | 페일블루 + 네이비 + 터쿠아즈 | 여름, 배달, 음료, 해산물, 야외 |
| `appetizing_premium` | 아이보리 + 버건디 + 뮤트골드 | 밀키트, 프리미엄 식품, 런치 |
| `playful_retro` | 오프화이트 + 토마토레드 + 리프그린 | 캐릭터 상품, 유스, 소셜 타일 |
| `pop_contrast` | 새추레이티드 퍼플 + 형광라임 | 고에너지 배달, 한정 이벤트, 엔터 |
| `violet_neon` | 딥바이올렛 + 민트네온 | 프리미엄/테크, 야간 톤 |
| `coral_warm` | 코랄 + 버건디 + 딥틸 | 따뜻함, 여성 타깃, 주광 |
| `mint_fresh` | 민트 + 네이비 + 코랄 | 청량, 의료, 밝은 톤 |

각 프리셋은 토큰 8개 + `usage`(어느 토큰을 어디에) + `avoid` + `area_budget` + 대비비를 함께 준다. 8종 전부 헤드라인·본문·CTA 대비 **4.5 이상 검증됨**. `pop_contrast`는 bg가 채도면인 반전 구조라 `contrast.text_ground`가 `bg`로 온다 — 텍스트를 surface에 올리면 안 읽힌다.

**색 결정 절차 (2026-07-30 — 이 절차를 건너뛰면 "랜덤한 색"이 된다):**

위 실전 분포(무채 패널 + 포인트 1색)는 **영상 위에 정보를 얹는 경우의 안전한 기본값**이다. 배너·그래픽 존까지 이걸로 덮으면 밋밋해진다 — 그쪽은 아래 스킴으로 간다.

1. `get_frame_palette`(draft_id, at_ms) — 화면 실제 색(`dominant`·`tone`)을 읽는다. 충돌하면 위 분포보다 이 응답이 우선.
2. **스킴 확정**: 응답의 `scheme`(지배색 파생) 또는 `get_color_scheme(preset)` 중 하나 — 브랜드/업종 톤이 정해져 있으면 위 레시피 8종에서 고르는 게 자동 파생보다 결과가 좋다. 토큰 8개(bg/surface/surfaceAlt/accent/accentSoft/textPrimary/textSecondary/line)를 스펙에 적고 **그것만** 쓴다.
3. **존별 적용**:
   - 그래픽 존(카드·밴드·레터박스·블롭·CTA) → `surface`/`surfaceAlt` 면색 + `surfaceGradient`(135° 대각 워시)로 미세한 톤 전환
   - 살아있는 영상 위 텍스트 → 무채 `scrim`(`angleDeg:180`, 투명→검정). 여기에 컬러 서피스를 쓰면 영상과 싸운다
   - `accent` → CTA 등 **1개 요소만**. 서브 강조는 `accentSoft`
4. `contrast` 4.5 미달이면 텍스트색이 아니라 **surface 명도**를 조정한다 (포인트색을 밝히면 채도 경쟁이 생긴다). `text_ground` 를 먼저 확인 — 반전 스킴은 bg 기준이다.
4-1. **면적 예산 확인**: accent 3~10% 를 넘겼는지 프리뷰에서 눈으로 대조. 넘겼으면 accent 면적을 줄이고 `accentSoft`/`surfaceAlt` 로 대체한다.
5. 하드 엣지 불투명 패널은 스티커처럼 뜬다 — 세로로 긴 패널은 특히 스크림이 정석.
6. 순회색(`#888`·`#CCC`) 금지. 회색이 필요하면 `textSecondary`/`line`(base hue가 섞인 저채도)을 쓴다.

## 2-1. 깊이 3종 — 라디얼 글로우 / 네온 / 글래스 (2026-07-30 추가, 프리뷰 픽셀 검증됨)

평면 사각형을 더 쌓지 말고 이 3개로 깊이를 만든다. 전부 `shape` 인자에 들어간다.

**라디얼 글로우 오브** — `backgroundRadialGradient`. 피사체 **뒤**(낮은 z)에 깔아 조명처럼 쓴다. 선형보다 우선 적용된다.
```json
{"shapeKind":"rect","backgroundOpacity":1,
 "backgroundRadialGradient":{"cx":50,"cy":50,"radius":75,"shape":"circle",
   "stops":[{"color":"<accent>","offset":0,"opacity":0.5},{"color":"<accent>","offset":100,"opacity":0}]}}
```
- cx/cy/radius는 **박스 기준 %** 라 포맷이 바뀌어도 그대로 재사용된다
- 끝 stop은 반드시 `opacity: 0` — 안 그러면 경계선이 보인다
- `shape:"circle"`도 내부적으로는 `ellipse R% R%`로 렌더된다(CSS가 circle에 %를 금지). 정사각 박스면 완전한 원, 아니면 박스 비율의 타원 → 글로우 용도로는 이게 맞다

**네온 글로우 / 그림자** — `effects`. 글로우는 offset 0 + 큰 blur.
```json
"effects":{"shadowColor":"<accent>","shadowBlur":70,"shadowSpread":12,"shadowOffsetX":0,"shadowOffsetY":0}
```
- 일반 그림자는 `shadowOffsetY` 2~8 + 어두운 저알파색. **모든 레이어의 offsetY 부호·값을 통일**할 것(광원 하나)
- `shadowSpread`는 rect 전용 — circle/triangle/svg는 `drop-shadow`로 렌더되어 spread가 무시된다
- 글로우가 있는 레이어는 렌더러가 박스 클리핑을 자동으로 푼다(안 그러면 글로우가 잘려 안 보임)

**글래스모피즘** — `effects.backdropBlur`. **반투명 배경과 함께 써야** 의미가 있다.

> **⚠️ 밝은 배경에서 흰 유리는 금지 (2026-08-01 실측).** `rgba(255,255,255,0.16)` 유리를 밝은 벽 위에 올리면 pill 이 거의 흰색이 되고, 흰 글자를 얹으면 **대비 1.04** — 글자가 사라진다. 배경이 밝으면 **어두운 유리**(`rgba(0,0,0,0.45)` + `borderColor rgba(255,255,255,0.45)`)로 뒤집을 것. 어느 쪽이든 **합성 후 픽셀로 대비를 재고** 4.5 를 넘는 최소 알파를 고른다.
```json
{"backgroundColor":"#FFFFFF","backgroundOpacity":0.18,"borderRadius":10,"borderWidth":1,"borderColor":"<line>",
 "effects":{"backdropBlur":26}}
```
- 불투명 배경 뒤는 블러해도 안 보인다 → opacity 0.15~0.35 구간이 정석
- rect 전용. 1~2px 밝은 보더를 같이 넣으면 유리 엣지가 살아난다

**함정 1 — 그라데이션 방향**: `angleDeg 180` 은 CSS `linear-gradient` 그대로라 **`offset 0` 이 화면 위**다. 스크림은 **텍스트가 있는 쪽이 어두워야** 한다 — 텍스트가 상단이면 `offset 0` 을 어둡게. 반대로 넣으면 피사체를 덮고, 도형이 끝나는 y 에서 불투명도가 뚝 끊겨 **가로 이음선**이 생긴다. **끝 stop 은 반드시 `opacity 0`**, 중간 stop 을 하나 넣어야(예 `0.88 → 0.62 → 0`) 경계가 안 보인다.

**함정 2 — 프레임은 클리핑하지 않는다**: 글로우가 달린 pill 을 프레임 자식으로 넣으면, 예전엔 부모 프레임의 `overflow:hidden` 이 글로우를 잘라 **둥근 알약 주위에 사각 후광**이 생겼다(2026-08-01 수정 — 프레임은 이제 항상 `overflow:visible`). 오래된 렌더러를 쓰는 환경이면 이 증상이 남아 있을 수 있다.

**함정 3 — `backgroundOpacity` 기본값**: 안 보내면 **0.6** 이 들어간다. 불투명 pill 을 원하면 `backgroundOpacity: 1` 을 명시할 것 — 안 그러면 색이 흐려져 "왜 이렇게 뿌옇지" 하게 된다.

**함정 4**: 같은 호출에 단색(`backgroundColor`)을 함께 보내면 **단색이 이기고 그라데이션(선형·라디얼)이 지워진다.** 스크림/글로우로 바꿀 때는 그라데이션만 보낼 것.

## 2-2. 프레임(flexbox) — 박스 안에 글자를 넣는 정석

칩·뱃지·pill·CTA·라벨 락업은 **도형+텍스트 2개가 아니라 프레임 1개 + 자식**이다.

```
add_frame_layer  { layout:{direction,justify,align,gap,padding}, shape:{backgroundColor,borderRadius,effects} }
  └─ add_text_layer { parent_id: <프레임 id>, width: <프레임 내부폭> }
```

| 용도 | direction | justify | align | padding |
|---|---|---|---|---|
| 칩 / pill / CTA | row | center | center | 16~20 |
| 빅넘버 락업(숫자+단위) | row | flex-start | center | 0, gap 16~20 |
| 불릿 항목(도트+텍스트) | row | flex-start | center | 0, gap 12~14 |
| 정보 블록(제목+설명) | column | flex-start | flex-start | 16~24, gap 8 |

- **`auto_width: true` 를 켜라.** 프레임이 콘텐츠에 맞게 줄어들어 **글자폭 계산이 필요 없다**. x/y 는 그대로 좌상단 기준이다. (끄면 `width` 를 직접 맞춰야 하고, 모자라면 2줄로 접혀 pill 이 깨진다)
- 배경·라운드·글로우는 프레임이 갖는다. 자식은 타입만
- 프레임 id 는 서버 생성이라 **프레임 먼저 만들고 id 를 받아 자식을 붙이는 2단계**
- 자식은 `positionMode:'flow'` 로 저장돼야 한다(도구가 자동 처리). `absolute` 면 (0,0) 에 쌓인다
- 자식 텍스트는 **자연폭**을 갖는다(렌더러가 `max-content` 로 처리). x/y/width 를 신경 쓸 필요 없다
- **중첩이 정석**: pill 2개를 나란히 → 각 pill 이 프레임, 그 둘을 `row` 프레임에 담고 `gap` 으로 간격. 헤드라인 2줄+룰+서브 → `column` 프레임 하나(`gap 10~12`)
- 만든 뒤 정렬을 고칠 땐 `update_layer_box` 의 `layout` 부분 patch (`{padding:20}` 만 보내도 됨). 재부모화도 같은 도구
- 불릿 도트는 도형 자식보다 **`·  ` 접두 문자**가 낫다 — 베이스라인이 자동으로 맞는다

## 2-3. 장르 레시피 6종 — **소재마다 하나를 고르고 그 안에서만 논다**

같은 도구로 10개를 만들면 10개가 똑같아진다. 원인은 취향이 아니라 **기본값으로 회귀**다 — 칩 → 대형 헤드라인 → 언더라인 → HUD 브래킷이 항상 "작동"하기 때문에 매번 그리로 돌아간다.

그래서 각 레시피에 **쓸 장치와 금지 장치를 같이 못박는다. 금지 목록이 본체다.**

| 레시피 | 쓴다 | **금지** |
|---|---|---|
| **에디토리얼** | 대형 세리프, 헤어라인 룰(1~2px), 비대칭 여백, 좌측 고정 정렬, 캡션 각주 | HUD 브래킷, 칩/pill, 글로우, 고채도 액센트 |
| **키네틱 타이포** | 텍스트가 주인공(풀블리드), 단어 단위 스태거, `blend_mode:'screen'`, 배경 블러 | 패널, pill, 언더라인, 도형 일체 |
| **다큐 로워서드** | 하단 이름표 바, 타임스탬프, 얇은 구분선, 좌하단 고정 | 대형 훅, 중앙 정렬, 액센트 2색 |
| **리테일 팝** | 두꺼운 아웃라인, 스티커(`rotation -3~-5°`), spring, 고채도 2색, 뱃지 | 스크림, 미니멀 여백, 얇은 폰트 |
| **미니멀 럭셔리** | 요소 2개 이하, 극단적 여백, `letterSpacing 8+`, 무채, 아주 느린 켄번스 | 액센트색, 도형 3개 이상, 밀도 규칙 |
| **HUD/테크** | 코너 브래킷, 텔레메트리 스택, 타임코드 티커, 대자간, 레티클 | 세리프, 곡선 장식, 파스텔 |

**운영 규칙**
- 소재 시작 시 레시피를 **먼저 선언**하고 디자인 스펙 맨 위에 적는다. 중간에 섞지 않는다.
- **직전 2개 소재와 같은 레시피를 쓰지 않는다.** 같은 제품군이라도 훅이 다르면 문법이 달라도 된다.
- 레시피가 정해지면 §1 골격 분포는 **그 레시피가 허용하는 범위 안에서만** 샘플링한다 (예: 키네틱 타이포는 TEXT_ONLY 고정).
- 밀도(철칙 3)는 레시피가 이긴다 — 미니멀 럭셔리에 5~9레이어를 넣으면 촌스러워진다.

## 2-4. 블렌드·마스크 — 패널 없이 대비를 얻는 법 (2026-08-02 추가)

지금까지 텍스트 대비는 **전부 스크림/패널을 깔아서** 얻었다. 그래서 결과가 늘 "영상 위에 검은 판때기 + 글자"로 수렴했다. 이제 두 가지가 더 있다.

**`blend_mode`** — 레이어를 영상 **안으로** 섞는다.
- `screen` : 밝은 글자가 어두운 영상 위에서 빛나듯. **스크림 없이** 밝은 부분만 살아난다
- `multiply` : 어두운 글자가 밝은 영상에 잉크처럼 인쇄된다. 밝은 제품컷에 유효
- `overlay`/`soft-light` : 톤 얹기. 컬러 워시를 배경에 깔 때
- 주의: 검은 배경에 흰 글자를 `screen` 하면 **아무 변화가 없다**(정상). 배경에 중간 톤이 있어야 의미가 생긴다

**`mask`** — 사각 wipe 4방향 말고 다른 리빌.
```json
{"kind":"circle","cx":30,"cy":50,"size":70,"feather":20}   // 원형 아이리스
{"kind":"linear","angleDeg":180,"size":60,"feather":25}    // 방향성 페이드
```
- `size` 는 박스 기준 %, `feather` 가 가장자리를 부드럽게 한다(0이면 하드 엣지)
- 텍스트 레이어에 걸면 **글자가 서서히 드러나는** 연출, 도형에 걸면 경계 없는 그라데이션 패널
- 프레임 자식에도 적용된다

## 7. 고급 테크닉 (2026-07-24 우주 컨셉 v4에서 검증)

- **타임코드 시퀀싱**: 같은 위치에 start/end_ms만 다른 텍스트 레이어를 연속 배치하면 **실시간으로 바뀌는 카운트다운/티커**가 된다 (T-MINUS 00:00:03→02→01, ALT 0.4→1.8→4.2 KM). 마지막 카운트는 색 전환(앰버→레드)으로 긴장감.
- **HUD 프레임**: 얇은 rect 2개(가로+세로)로 코너 브래킷 틱 — 4코너 = 8 rect. 흰 70%.
- **타겟 레티클**: circle 도형(배경 투명+border 2px) + 상하좌우 틱 rect 4개 + 라벨 slideRight — 피사체 위 조준선.
- **텔레메트리 스택**: 좌측 소형 라벨들 순차 slideRight(스태거 500ms) — 발사 중계 감성.
- **스탬프 타이포**: rotation -2~-4° + scale spring 등장 = 도장 찍히는 임팩트.
- **생성 이미지 에셋화**: generate_image로 엠블럼/뱃지(검정 배경 지시)를 만들어 `add_image_layer`로 재활용 — 어두운 씬 위에서 배경이 자연 블렌딩. 미션 패치, 씰, 아이콘류에 유효.
- **장르 문법 선택**: 럭셔리=미니멀 세리프+절제 / 스페이스·테크=HUD 텔레메트리+대자간+코너틱 / 퍼포먼스=패널+뱃지+CTA. 소재 장르 보고 문법부터 고른다.
